# 🏥 System Health Dashboard

Real-time view of system health. Update weekly. Act on amber. Fix red immediately.

---

## How to Read This

🟢 Green = System is healthy. No action needed.

🟡 Amber = Warning signs. Monitor closely. Intervene if it doesn’t resolve in 5 days.

🔴 Red = System is breaking. Immediate action required.

## Green Thresholds

- VA Output: 90%+ of VAs hitting weekly outreach target
- QC Score: 90%+ of reviewed messages pass QC
- Booking Rate: At or above monthly target
- Supervisor Coverage: Deputy Protocol in place, no uncovered days
- Report Submission: 95%+ submitted on time

## Amber Thresholds

- VA Output: 70-89% of VAs hitting target
- QC Score: 75-89% pass rate
- Booking Rate: 10-20% below target
- Supervisor Coverage: Deputy not confirmed
- Report Submission: 80-94% submitted on time

## Red Thresholds

- VA Output: <70% hitting target
- QC Score: <75% pass rate
- Booking Rate: >20% below target
- Supervisor Coverage: No coverage at all
- Report Submission: <80% submitted on time

---

## Red Alert Protocol

When any layer turns red:

1. Identify root cause (person issue or system issue?)
2. If person issue: coaching plan or replacement decision
3. If system issue: log in System Feedback Log and fix within 72 hours
4. Update this dashboard after fix
5. Monitor for 2 weeks before returning to green
