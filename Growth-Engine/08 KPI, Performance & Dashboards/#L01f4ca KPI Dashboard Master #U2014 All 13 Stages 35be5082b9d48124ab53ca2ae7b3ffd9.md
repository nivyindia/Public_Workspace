## 🗓️ How to Use This Page

Every Monday at 8am (or when your n8n weekly report arrives):

1. Pull numbers from HubSpot, Instantly, Mautic/Brevo, and Stripe
2. Fill in the **Current** column for each KPI
3. Check the **Status** — 🟢 On Track | 🟡 Warning | 🔴 Action Required
4. Read the **If Off-Target** column and execute the fix

## 🚦 Status Key & Corrective Action Rules

| Status | Meaning | Action Required |
| --- | --- | --- |
| 🟢 On Track | At or above target | Maintain. Document what's working. |
| 🟡 Warning | 10–20% below target | Identify root cause. Fix within this week. |
| 🔴 Action Required | >20% below target or not set up yet | Stop and fix today before moving to other tasks. |
| ⚫ Not Started | Tool/system not yet built | Check which Phase it belongs to and build it. |
