## 🎯 PURPOSE

This SOP governs the **setup and ongoing management** of paid advertising campaigns for clients. Ads are the highest-ROI service Nivy delivers — but also the highest-risk if done wrong. Every VA managing ads must follow this SOP exactly. No campaigns go live without Supervisor sign-off.

> ⚠️ **Hard rule:** No ad account gets touched without written client authorisation. No budget gets spent without Supervisor approval. No campaign goes live without QC sign-off.

## 🗓️ STARTER L1 — ADS SETUP DELIVERY (One-Time, 7–10 Days)

### Day 1–2 — Client Onboarding & Access

- [ ]  Send Ads Onboarding Form: collect business goal (leads / sales / awareness), target audience description, budget/day, ad account access, Facebook Page access, website URL, pixel status
- [ ]  Access: request Admin access to Facebook Business Manager (not just ad account)
- [ ]  Verify pixel is installed on website. If not → send pixel installation guide to client.
- [ ]  Confirm campaign objective: Lead Generation / Traffic / Conversions / Awareness
- [ ]  Log all access details in internal tracker (never save passwords — use access sharing only)

### Day 3–4 — Audience Research & Campaign Structure

- [ ]  Build 2–3 audience sets using Facebook Audience Insights:
    - Audience 1: Interest-based (broad niche targeting)
    - Audience 2: Competitor/page targeting
    - Audience 3: Lookalike (only if existing customer list available)
- [ ]  Define campaign structure:
    - 1 Campaign → 2 Ad Sets → 2 Ads per Ad Set (= 4 ads total)
- [ ]  Submit audience research + campaign structure to Supervisor for approval before creating anything in Ads Manager

### Day 5–6 — Ad Creative Production

- [ ]  Write 2 ad copy variations (Primary Text + Headline + Description):
    - Copy format: **Problem → Solution → Proof → CTA**
    - Headline: max 7 words, benefit-first
    - CTA button: “Learn More” / “Sign Up” / “Get Quote” / “Shop Now” (match objective)
- [ ]  Design 2 ad visuals in Canva:
    - Size: 1080×1080 (feed) + 1080×1920 (stories)
    - Include: hook text, brand colours, logo, clear offer
    - No more than 20% text on image (Facebook rule)
- [ ]  Submit creatives to Supervisor for QC before uploading

### Day 7–8 — Campaign Build & Pre-Launch QC

- [ ]  Build campaign in Facebook Ads Manager:
    - Campaign level: set objective, campaign budget (if CBO)
    - Ad Set level: audience, placement (automatic), schedule, budget
    - Ad level: upload creative, copy, CTA, destination URL
- [ ]  Pre-launch checklist (do not launch without all ticks):
    - [ ]  Pixel firing confirmed on thank-you/confirmation page
    - [ ]  Destination URL working and loads under 3 seconds
    - [ ]  Ad copy reviewed — no spelling errors, no prohibited content
    - [ ]  Budget confirmed with client in writing (WhatsApp/email)
    - [ ]  Supervisor sign-off received
- [ ]  Launch campaign
- [ ]  Monitor first 6 hours: check for disapprovals, delivery issues, abnormal spend

### Day 9–10 — Handover

- [ ]  Confirm campaign is delivering normally (impressions, clicks, no flags)
- [ ]  Send client a Campaign Launch Summary: campaign name, objective, budget/day, audience summary, ad previews
- [ ]  If client wants ongoing management → transition to Growth L2 SOP below

## 🔄 GROWTH L2 — MONTHLY ADS MANAGEMENT CYCLE

### WEEK 1 — REVIEW & PLANNING (Day 1–5)

- [ ]  Pull last month’s performance data: CPM, CPC, CTR, CPA (cost per result), ROAS (if ecom), spend vs budget
- [ ]  Identify winners (CTR > 2%, CPA below target) and losers (CTR < 1%, high CPA)
- [ ]  Pause underperforming ads (if running for 7+ days with no result)
- [ ]  Write Month N+1 strategy: what to test, new audiences, new creatives
- [ ]  Submit strategy to Supervisor for approval

### WEEK 2 — NEW CREATIVE PRODUCTION (Day 6–12)

- [ ]  Produce 4 new ad variations (2 copy + 2 visual minimum):
    - At least 1 video/reel ad + 1 static image ad
    - Test: new hook vs old hook, new audience vs existing
- [ ]  A/B test rule: change ONE variable at a time (copy OR visual OR audience, never all three)
- [ ]  Submit to Supervisor for QC before uploading
- [ ]  Upload and launch new ads alongside existing winners

### WEEK 3–4 — OPTIMISATION & REPORTING (Day 13–28)

**Daily Monitoring (5–10 min per client)**

- [ ]  Check spend vs daily budget (within 10% variance is normal)
- [ ]  Check for ad disapprovals (fix within 4 hours)
- [ ]  Check frequency (if > 3.0, audience is fatigued → new creative needed)
- [ ]  Log any anomalies in client tracker

**Weekly Report (every Friday)**

- [ ]  Fill Weekly Ads Report Template: spend, impressions, reach, clicks, CTR, CPC, results, CPA
- [ ]  2-line summary: what performed, what changed
- [ ]  Submit to Supervisor → Supervisor sends to client

**Monthly Report (Day 28)**

- [ ]  Full month summary: total spend, total results, CPA trend, best ad, worst ad, recommendation for next month
- [ ]  Submit to Supervisor by Day 28
- [ ]  Supervisor conducts 30-min strategy call with client

## ✅ QUALITY CONTROL CHECKLIST (Supervisor Use)

**Before any campaign goes live:**

- [ ]  Client has given written budget approval
- [ ]  Pixel confirmed firing on conversion page
- [ ]  Ad copy: no prohibited words (free, guaranteed, before/after, personal attributes)
- [ ]  Ad visual: text under 20% of image
- [ ]  Destination URL loads correctly, no 404
- [ ]  Campaign objective matches client goal
- [ ]  Audience size: minimum 500K (too narrow = won’t deliver)
- [ ]  VA has Supervisor sign-off in writing before launch

**Monthly (Growth L2):**

- [ ]  Weekly reports sent every Friday
- [ ]  Underperforming ads paused within 7 days of confirmed underperformance
- [ ]  New creatives tested every month
- [ ]  Monthly report submitted by Day 28

## ⚠️ ESCALATION RULES

| Situation | Action | Who Handles |
| --- | --- | --- |
| Ad disapproved by Meta/Google | Review policy, fix creative/copy, resubmit. Flag if rejected twice. | VA fixes first attempt. Supervisor handles appeal. |
| CPA exceeds target by 50%+ for 7 days | Pause campaign. Flag to Supervisor immediately. | Supervisor + VA review strategy together |
| Accidental overspend beyond client budget | Pause all ads. Notify Supervisor immediately. | Supervisor handles client communication |
