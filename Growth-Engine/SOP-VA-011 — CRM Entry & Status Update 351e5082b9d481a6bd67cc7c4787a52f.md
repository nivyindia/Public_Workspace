# SOP-VA-011 — CRM Entry & Status Update

> **Version:** 1.0 | **Last Updated:** April 29, 2026 | **Owner:** VA Manager | **Status:** Live
> 

> **Who Uses This:** VA Intern, VA Executive, VA Manager
> 

---

## Purpose

To ensure every lead is entered into the CRM with the correct fields, and every status change is updated within the defined time window.

---

## CRM Field Definitions

| Field | What to Enter | Rules |
| --- | --- | --- |
| Lead Name | Full name | First + Last. No nicknames. |
| Job Title | Exact title from LinkedIn or website | Do not abbreviate or guess |
| Company Name | Official company name | Exactly as it appears |
| LinkedIn URL | Full URL | [https://linkedin.com/in/](https://linkedin.com/in/)... |
| Website | Company website URL | If available |
| Email | Verified email | Only if sourced from Apollo or directly given |
| Phone | Phone number with country code | +1, +44, +971, etc. |
| Market | US / UK / Canada / AU / UAE | Exact value from this list only |
| Industry | Assigned industry category | Standardised list — do not invent categories |
| Source | LinkedIn / Google Maps / Apollo / Referral / Other | Exact value |
| Date Added | Today's date | yyyy-mm-dd format |
| Assigned VA | Your name |  |
| Status | See status list below |  |
| Qualification Score | 1–5 | From SOP-VA-004 |
| First Contact Date | Date of Message 1 | yyyy-mm-dd |
| Last Contact Date | Date of most recent outreach | Update after every touch |
| Follow-Up Stage | FU0 / FU1 / FU2 / FU3 / FU4 | FU0 = not yet contacted |
| Notes | 1–2 lines of context | Pain signal, lead source detail, or conversation summary |

---

## Status Values (Use Exactly These — No Custom Values)

| Status | Meaning | Update Timing |
| --- | --- | --- |
| New | Added, not yet contacted | On entry |
| Contacted | First message sent | Within 1 hour of sending |
| Following Up | In follow-up sequence | After each follow-up sent |
| Interested | Replied positively | Within 30 minutes of reply |
| Booked | Call confirmed | Within 30 minutes of confirmation |
| Called | Discovery call completed | Same day as call |
| Closed Won | Became a client | On payment confirmed |
| Closed Lost | Did not convert | After closer confirms outcome |
| Dead | Unresponsive after full sequence OR asked not to be contacted | Same day |

---

## Step-by-Step: Adding a New Lead

1. Check for duplicate (search name + company before adding)
2. Open a new row in CRM
3. Fill in all required fields (blank cells are not acceptable)
4. Set Status: New
5. Set Qualification Score (from SOP-VA-004)
6. Save and confirm row is complete

---

## Step-by-Step: Updating Status

1. Find the existing lead row
2. Update the correct status from the approved list
3. Update Last Contact Date
4. Update Follow-Up Stage if relevant
5. Add a note if anything notable happened (reply text, reason for Dead, etc.)

---

## Update Time Rules (SLA)

| Trigger | CRM Update Deadline |
| --- | --- |
| New lead added | Same day |
| Message sent | Within 1 hour |
| Lead replies (any response) | Within 30 minutes |
| Lead replies positively (Interested) | Within 30 minutes |
| Call booked | Within 30 minutes |
| Lead marked Dead | Same day |

---

## Output Standard

- Zero blank required fields
- Status always reflects current actual state
- Last Contact Date always updated after every touch
- No custom status values (use only approved list)

---

## Common Mistakes

- Leaving required fields blank and submitting anyway
- Using informal status labels ("maybe", "pending", "warm") — not in the approved list
- Not updating Last Contact Date — this breaks follow-up scheduling
- Not adding Notes — the Manager cannot QC without context
- Duplicate entries — always search before adding

---

## QC Checklist

- [ ]  All required fields filled
- [ ]  Status is from the approved list
- [ ]  Qualification score entered
- [ ]  Last Contact Date updated
- [ ]  Notes field has at least 1 line
- [ ]  No duplicate created
