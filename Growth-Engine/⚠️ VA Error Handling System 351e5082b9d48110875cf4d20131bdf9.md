# ⚠️ VA Error Handling System

> **Version:** 1.0 | **Last Updated:** April 29, 2026 | **Owner:** VA Manager | **Status:** Live
> 

---

## Purpose

Every error type that can occur in the VA operation has a defined owner, a required response action, and a resolution timeline. No error should be improvised. No error should be hidden.

---

## Error Response Matrix

| Error Type | Who Owns the Fix | Required Action | Resolution Timeline |
| --- | --- | --- | --- |
| **Wrong or duplicate CRM entry** | VA | Correct and resubmit immediately. Add note explaining the correction. | Within 2 hours of discovery |
| **CRM not updated within SLA** | VA | Update immediately + note the delay reason in CRM. | Same day |
| **Missed daily target (<50% of target)** | VA + Manager | VA flags in daily report. Manager initiates 1:1 call to identify blocker. | Same day |
| **QC checklist not completed before submission** | VA | Complete checklist and resubmit. Work is rejected until checklist is done. | Immediate |
| **Daily report not submitted by 6:00 PM** | VA | Submit immediately upon realising + add written explanation in the report. | Same day |
| **Follow-up sent outside the cadence window** | VA | Note in CRM. Do not send extra messages to compensate. Adjust next follow-up accordingly. | Next CRM update |
| **Outreach quality rejected by Manager** | VA | Rewrite with Manager’s feedback. Resubmit for review before sending. | Within 4 hours |
| **Interested lead not escalated within 30 minutes** | VA | Escalate immediately upon discovery. Log delay. Manager decides whether to proceed with that lead. | Immediate |
| **Call Handover Form submitted late** | VA | Submit immediately. Manager notifies closer of late submission. | Immediate |
| **Lead treated disrespectfully / prospect complaint** | Manager + Ops Head | Manager escalates to Ops Head within 1 hour. Formal review held. Response sent to lead if appropriate. | Immediate |
| **VA no-show (unreachable during working hours)** | Manager | Two contact attempts (WhatsApp + call). If no response in 2 hours → escalate to Ops Head. | Within 2 hours |
| **System or tool failure (CRM, LinkedIn, email)** | VA flags → Manager resolves | VA notifies Manager via WhatsApp within 1 hour. Manager identifies workaround or escalates to Ops Head for tool fix. | Within 2 hours of report |
| **Outreach volume limit exceeded** | VA | Stop immediately. Log in daily report. Manager reviews account status. Do not send further messages that day. | Immediate |
| **Data quality issue identified in bulk import** | VA Executive | Run data cleaning per SOP-VA-012. Log cleaning report. | Within same day of import |
| **Incorrect status in CRM (e.g., marked Booked without confirmation)** | VA | Correct immediately. Add note with correction reason. | Immediate |
| **Manager missing Monday review** | Manager | Complete by end of Monday. Send Ops Head summary by 12:00 PM Tuesday at the latest. | Same week |

## Error Escalation Levels

| Level | Who Handles | Examples |
| --- | --- | --- |
| **Level 1 — VA self-corrects** | VA alone | CRM update error, QC missed, follow-up timing slip |
| **Level 2 — Manager involved** | VA + Manager | Missed target, quality rejection, outreach limit breach, tool failure |
| **Level 3 — Ops Head involved** | Manager + Ops Head | Prospect complaint, VA no-show, serious data breach, repeated Level 2 errors from same VA |

---

## Retraining Trigger Criteria

A formal retraining plan is initiated when:

- Same error type occurs 3+ times in one week from the same VA
- VA scores below 60% for 2 consecutive weeks
- A serious Level 3 error occurs

**Retraining format:**

1. Manager identifies the specific SOP or KB page that failed
2. VA re-reads the relevant page and submits a 5-question self-quiz on it
3. Manager reviews quiz, confirms understanding
4. VA operates under daily check-in for 5 working days
5. If performance improves → standard operations resume
6. If no improvement after retraining → Ops Head review

## Error Reporting Culture

> **Errors hidden are problems doubled. Errors flagged are problems halved.**
> 

The Nivy VA team operates with a no-blame error culture:

- Flagging an error early is rewarded, not punished
- Hiding an error that then cascades is a serious breach of trust
- The error handling system exists to fix problems, not to assign blame

Every Manager and VA is expected to flag errors immediately and apply the correct response from this table — no improvisation required.
