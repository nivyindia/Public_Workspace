# Keyword Map by Country

**Module:** 05 — Channels & Sales Systems (Content & SEO, Deliverable 6) | **Status:** Draft v1 — desk-research hypothesis, NOT pulled from Ahrefs/Semrush/GSC | **Last updated:** 2026-08-06

## Important Caveat — Read Before Using

Nivy Next has no live clients, no domain history, and no paid keyword-research tool connected yet (Task 42 in the roadmap calls for Ahrefs/Semrush). This map is built from category knowledge, competitor-content patterns, and 2026 search-behavior research (see sources below) — **not real volume/difficulty data**. Treat every number in this doc as a directional placeholder. The moment a keyword tool is connected, replace this file entirely rather than patch it.

**2026 context that changes how this map should be used** (confirmed via current research, not assumption): B2B buyers increasingly research through AI answer engines (ChatGPT, Perplexity, Google AI Overviews) before ever opening a search results page — traffic from AI-search referrals grew sharply through 2025–2026. That means the old model of "rank #1 in Google" is necessary but no longer sufficient. Every priority topic below should be built for **both traditional SEO and AI answer-engine optimization (AEO/GEO)**: clear direct-answer structure, genuine expertise/data (not generic AI-written filler — which is now table stakes and doesn't differentiate), and content structured so an AI system can extract and cite it accurately.

---

## Methodology (once a real tool is connected)

1. Seed list = service line × ICP pain language (pull from VoC interviews once run — see Deliverable 5).
2. Expand via Ahrefs/Semrush + Google autocomplete/"People Also Ask."
3. Segment by intent: informational / comparison / transactional.
4. Score by volume × difficulty × buyer-intent fit; prioritize comparison/transactional first, informational second (for AEO/top-of-funnel authority).
5. Re-run quarterly — search behavior (especially AI-search share) is moving fast in 2026.

## Content-Format Implication for Each Intent Tier

| Intent | Best Format | AEO/GEO Note |
|---|---|---|
| Informational | Pillar/cluster blog content, original data/POV pieces | Structure with direct-answer summaries near the top — AI answer engines extract these first |
| Comparison | "X vs Y" pages, alternative pages, objection-led FAQ | High-value for both SEO and AI citation — write with genuine specificity, not generic claims |
| Transactional | Service/pricing pages, case studies | Needs strong trust signals (Module 06) since this is where buyers convert |
