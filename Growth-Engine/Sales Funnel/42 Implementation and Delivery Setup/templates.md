## Delivery Setup Checklist (internal, per new client)
```
[ ] Task board created from [Service] delivery SOP template
[ ] Client-specific customizations logged (brand tone, do-not-post list, etc.)
[ ] Delivery specialist assigned: [Name]
[ ] Team lead assigned for QC: [Name]
[ ] Platform access tested and confirmed working:
    [ ] Analytics
    [ ] Ad accounts (if applicable)
    [ ] CMS (if applicable)
    [ ] Social accounts (if applicable)
[ ] Tracking configured and verified (goals/conversions firing correctly)
[ ] Phase 1 (Foundation) activities scheduled
[ ] First deliverable target date: [date, within 7 days of kickoff]
```

## Phase 1 — Foundation (Weeks 1-4) Activity Template
```
Goal: Build a strong base for visibility and trust.

Key activities (adapt per service):
- Platform/profile optimization (categories, services, initial content)
- Baseline tracking setup (calls, forms, UTMs)
- Initial on-page/technical basics
- Review/reputation system setup (if applicable)

Client-visible outcome: improved presence, initial increase in visibility/inquiries.
```
