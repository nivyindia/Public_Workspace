# FAQ — 22 Personalization and Copywriting

[⬅ Back to README](README.md)

**Q: Is "Hi [First Name]" real personalization?**
No — that's Tier 1 (merge-field only). It's necessary but not sufficient; Stage 15-21 templates should aim for Tier 2 or 3 wherever the segment/contact data supports it.

**Q: How much does personalization actually improve reply rates?**
Track it per template using the KPI table in the README — this varies by segment and should be measured, not assumed, but Tier 3 outperforming Tier 1 is the expected and typically observed pattern.

**Q: Can AI write the whole personalization line unsupervised?**
For Tier 2 (industry-general) lines at scale, yes with spot-checking. For Tier 3 (contact-specific) lines, always spot-check before sending — a wrong or stale detail damages credibility more than generic copy would.

**Q: Who approves a new template before it goes live?**
A named approver per the workflow in Sub-Stage 22F — this should be a fixed role (e.g., team lead), not left ambiguous.

**Q: How is this different from each channel stage's own templates.md?**
Stages 16-21's templates.md files hold the actual channel-specific message text. This stage defines the *standard* those templates are written to and the personalization *method* used to fill them in.
