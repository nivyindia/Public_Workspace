# Checklists — 05 Lead Source Selection

> Part of Stage 05 (Lead Source Selection). See [README.md](README.md) for the full stage overview.

---

## Pre-Selection Checklist

- [ ] Active ICP(s) for this campaign confirmed (Stage 02)
- [ ] Target market confirmed and Stage 01 brief reviewed
- [ ] Source-performance log checked for prior data on candidate sources

## Selection Decision Checklist

- [ ] Selected source(s) documented with rationale tied to ICP/market fit
- [ ] Cost (if paid) and expected volume noted
- [ ] Compliance check completed for the target market (e.g. GDPR basis + unsubscribe option for UK/EU)
- [ ] Pilot batch planned for any newly-considered source before full-volume commitment

## Data Quality Rules (apply regardless of source)

- [ ] No unverified emails used for outreach — verify before sending
- [ ] Acceptable bounce rate target set at under 3%; pause and clean list if exceeded
- [ ] No personal mobile numbers used — business email/LinkedIn only
- [ ] Lists updated regularly — bounced emails, unsubscribes, and closed companies removed monthly

## Review Checklist (monthly)

- [ ] Source performance log updated
- [ ] Keep/rotate/drop recommendation reviewed and acted on
- [ ] Any source with rising bounce rate or falling qualified rate flagged for rotation
