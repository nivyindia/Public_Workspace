# FAQ — 05 Lead Source Selection

> Part of Stage 05 (Lead Source Selection). See [README.md](README.md) for the full stage overview.

---

**Q: Should we always start with a paid tool like Apollo, or test free sources first?**
A: Where a free/low-cost source plausibly covers the ICP (Google Maps, Companies House, JustDial), test it first with a small pilot batch. Reserve paid-tool budget for markets/ICPs where free sources genuinely don't have adequate coverage.

**Q: How many sources should we run per market at once?**
A: 2-4. Enough for redundancy if one source underperforms or gets depleted, without fragmenting extraction effort across too many sources to properly log and evaluate.

**Q: What triggers dropping a source?**
A: A sustained fall in qualified-lead rate, a rising bounce rate above 3%, or cost-per-qualified-lead that no longer justifies the spend relative to alternative sources — reviewed monthly per the performance log.

**Q: Do compliance checks apply to free sources too?**
A: Yes. GDPR and similar data rules apply to how contact data is used and how outreach is conducted, not to how much the source itself costs.

**Q: How does this stage relate to Stage 06 (Lead Extraction)?**
A: This stage is the decision ("which source, why, how much volume"); Stage 06 is the execution (actually pulling the leads from the chosen source using the sub-stage methods documented there).
