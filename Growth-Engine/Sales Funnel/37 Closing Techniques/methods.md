# Methods — 37 Closing Techniques

[⬅ Back to README](README.md)

## Traditional
High-pressure closing tactics (artificial urgency, aggressive assumptive closes) — deliberately not used here; this stage favors the source SOP's consultative, next-steps-driven close over pressure tactics.

## Modern / Tool-Assisted
A clear, standard "Next Steps" call-to-action embedded in every proposal (Stage 33): "sign below / reply to confirm / book a call if you have questions," with a stated validity window.

## AI-Assisted
LLM-assisted drafting of a final, low-pressure nudge message once a proposal has been viewed but not actioned, tailored to the specific stage of hesitation (see [templates.md](templates.md)).

## Manual
Recognizing buying signals in a live call or reply thread is a human judgment call — not automated.

## Automated
Automatic follow-up cadence (Stage 24/33) continues to fire on schedule until the prospect either signs, declines, or is moved to nurture — removing the "did anyone follow up?" gap.

## API / Integration
Proposal-tool view/open tracking (Stage 33) feeding the CRM so a rep knows when a prospect has re-opened a proposal — a signal worth a timely, non-pushy check-in.

## Method Selection Guidance
Default to the standard clear-CTA-plus-cadence approach; use a live nudge only when a genuine buying signal (re-opened proposal, direct question about start date, etc.) is observed — not on a fixed script regardless of signal.
