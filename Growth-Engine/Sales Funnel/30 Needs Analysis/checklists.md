# Checklists — 30 Needs Analysis

[⬅ Back to README](README.md)

## Extraction QC
- [ ] Every distinct problem mentioned on the call is captured, not just the first one discussed
- [ ] Each problem is traceable to something the prospect actually said, not a rep assumption
- [ ] Problems ranked by stated urgency/cost using the call's implication answers

## Completeness QC
- [ ] Every ranked problem has a desired-outcome entry, or is flagged as a gap
- [ ] Significant gaps trigger a follow-up clarification before finalizing
- [ ] Document reviewed by the rep, not left as an unreviewed AI draft

## Handoff QC
- [ ] Document status set to `Finalized` before Stage 31 begins
- [ ] Document attached to the correct CRM opportunity record

## Duplicate / Accuracy / Completeness Checks
- [ ] No conflicting needs-analysis versions for the same opportunity
- [ ] Ranking order matches what's carried into Stage 31/33
