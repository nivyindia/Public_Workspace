# Automation — 21 Multi Channel Sequencing

[⬅ Back to README](README.md)

## Manual
Designing and approving a new sequence blueprint per segment before it runs at volume.

## Semi-Automated
VA/rep reviews the day's "next step due" list generated by the orchestration layer and manually triggers channel-specific actions that require human judgment (e.g., a cold call).

## Full-Automated
Orchestration layer (n8n or a sales-engagement platform) advances contacts through channel-and-timing steps automatically, halting immediately on any reply across any channel.

## AI-Assisted Workflow
1. New segment enters a multi-channel sequence per Stage 15's channel plan.
2. LLM proposes a starting blueprint (channel order + timing) based on similar past-segment performance.
3. Human reviews/approves the blueprint before it's loaded into the orchestration layer.
4. Orchestration layer executes: Day 1 email (Stage 16) → Day 3 LinkedIn connect (Stage 17) → Day 6 call if no reply (Stage 18), etc.
5. A reply on any channel sets `overall_status = paused_replied` and halts all remaining automated steps for that contact.

## Suggested n8n / integration flow
`CRM (contact enters sequence)` → `n8n (step scheduler)` → `Channel tool API (Stage 16/17/18/19/20, per step)` → `Channel tool webhook (reply/no-reply)` → `n8n (advance or halt sequence)` → `CRM (log cross-channel timeline)`
