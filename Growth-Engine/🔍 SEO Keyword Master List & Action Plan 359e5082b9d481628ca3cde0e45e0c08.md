# ✅ ON-PAGE SEO ACTION PLAN {#on-page}

## For Every Page on the Website

- [ ]  **Title tag:** 50–60 characters | Include primary keyword near the front
    - Example: "Hire Virtual Assistants India | Nivy Digital Agency"
- [ ]  **Meta description:** 150–160 characters | Include keyword + compelling CTA
    - Example: "Nivy Digital places dedicated virtual assistants for businesses across US, UK & UAE. Hire your VA in 3–5 days. Book a free call today."
- [ ]  **H1 tag:** One per page | Contains primary keyword
- [ ]  **H2/H3 tags:** Supporting keywords naturally included
- [ ]  **First paragraph:** Include primary keyword within first 100 words
- [ ]  **Image alt text:** Descriptive + keyword-rich for all images
- [ ]  **Internal linking:** Every page links to 2–3 related pages
- [ ]  **URL slug:** Short, keyword-rich, no stop words
    - Example: `/services/virtual-assistant-india` not `/page?id=123`
- [ ]  **Page speed:** >70 on Google PageSpeed
- [ ]  **Schema markup:** Add FAQ schema to FAQ page, LocalBusiness schema to Contact page

## Blog Post SEO Template

For every blog post:

1. **Target keyword** in title + H1 + first paragraph + URL
2. **2–3 related keywords** in H2 subheadings
3. **1,500+ words** minimum (Google favors comprehensive content)
4. **Internal links:** Link to 2+ other blog posts + 1 service page
5. **External links:** Link to 1–2 high-authority sources
6. **Lead capture:** Embed relevant lead magnet or [Cal.com](http://Cal.com) CTA in post
7. **Social share buttons:** At top and bottom of post

# ⚙️ TECHNICAL SEO CHECKLIST {#technical}

- [ ]  Submit XML sitemap to Google Search Console
- [ ]  Verify robots.txt is not blocking important pages
- [ ]  All pages return 200 status (no 404 errors)
- [ ]  Canonical tags on all pages (prevent duplicate content)
- [ ]  Mobile-friendly test: pass Google Mobile-Friendly Test
- [ ]  Core Web Vitals: LCP < 2.5s, CLS < 0.1, FID < 100ms
- [ ]  HTTPS on all pages (SSL certificate active)
- [ ]  Schema markup: LocalBusiness, FAQPage, Organization
- [ ]  No broken internal links (check with Screaming Frog free)
- [ ]  Structured data tested via Google Rich Results Test
