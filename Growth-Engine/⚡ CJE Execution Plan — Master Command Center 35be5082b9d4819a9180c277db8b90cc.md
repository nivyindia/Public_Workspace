## 🚦 Phase-by-Phase Overview

### 🟥 Phase 1 — Foundation (Week 1–2)

**Goal:** First 50 leads in HubSpot. First 5 calls booked. Enquiry Method running daily.

| Day | Priority Task |
| --- | --- |
| Day 1 | HubSpot setup, Apollo scraping (first 50 leads), domain + email warmup |
| Day 2 | PhantomBuster LinkedIn scraping, Reoon validation, import to HubSpot |
| Day 3 | Cold email sequence written + loaded into Instantly |
| Day 4 | Google Maps scrape (local businesses), [Hunter.io](http://Hunter.io) email find |
| Day 5 | Enquiry Method posts live: LinkedIn + 3 Facebook Groups |
| Day 6–7 | WhatsApp community group created, first 20 members invited |
| Day 8 | Tally lead capture forms built (audit request + contact + community join) |
| Day 9 | [Cal.com](http://Cal.com) booking link live, Notion client portal template created |
| Day 10 | Cold email goes live (Day 1 of sequence) |
| Day 11–12 | Monitor replies, route HOT manually, refine subject lines |
| Day 13 | Lead magnet PDF created (checklist or guide) |
| Day 14 | Phase 1 review: leads captured, calls booked, reply rate |

**Exit criteria:** 50+ leads in CRM, 5+ calls booked, enquiry method running daily

## ⚠️ Common Failure Points to Avoid

| Failure Mode | Prevention |
| --- | --- |
| Building automation before getting first clients | Phase 1–2 are manual by design — automate after proof |
| Skipping email domain warmup | Warm domain 2 weeks before any cold sending |
| Not logging call notes in HubSpot | Non-negotiable SOP — log within 1 hour of every call |
| Sending generic cold emails | Every email must have 1 personalized opening line |
| Not following up after proposals | Automated follow-up in n8n — no manual required |
| Treating all leads equally | HOT leads get contact within 2 hours — every time |
| Building everything at once | Follow phase order strictly — foundation before automation |
