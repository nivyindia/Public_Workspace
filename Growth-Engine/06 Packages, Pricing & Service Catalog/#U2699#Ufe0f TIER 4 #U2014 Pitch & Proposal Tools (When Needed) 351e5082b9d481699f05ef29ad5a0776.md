# ⚙️ TIER 4 — Pitch & Proposal Tools (When Needed)

> **Who this is for:** Any VA preparing a client-facing proposal, pitch, or presentation
> 

> **Stage:** No stage gate — access any time you need it
> 

> **Rule:** Use these templates as-is. Do not invent formats. Every client communication follows one of these structures.
> 

---

## 📁 Available Format Templates

### 💰 Sales Version Format

Use when: Sending a written proposal to a lead before a call

Structure: Problem → Solution → Package → Investment → Next Step

→ 📦 **Sales Version Format Template**

### 📄 Proposal Version Format

Use when: Sending a formal proposal after a discovery call

Structure: Cover page → Summary → Scope → Deliverables → Investment → Timeline → Sign-off

→ 📄 **Proposal Version Format Template**

### ⚙️ SOP / VA Version Format

Use when: Preparing internal documentation or handoff notes

Structure: Objective → Steps → Owner → Deadline → Output

→ ⚙️ **SOP / VA Version Format Template**

### 🌐 Website Version Format

Use when: Briefing the web team or presenting a website package to a client

Structure: Pages → Features → Tech Stack → Timeline → Investment

→ 🌐 **Website Version Format Template**

### 📱 Social Media Version Format

Use when: Presenting a social media package

Structure: Platforms → Content plan → Frequency → Investment

→ 📱 **Social Media Version Format Template**

### 📊 Sales Deck / Pitch Deck Format

Use when: Presenting Nivy to a client in a call or video

Structure: Hook → Problem → Solution → Proof → Package → CTA

→ 📊 **Sales Deck / Pitch Deck Format Template**

---

## 🔑 Rules for Using These Templates

1. **Never send a proposal without Supervisor approval** — show draft first
2. **Always personalise** — replace all [bracketed] fields before sending
3. **Match the format to the situation** — Sales Version for early stage, Proposal for post-call
4. **Do not create your own format** — these exist for consistency and brand quality
5. **If unsure which format to use** — ask Supervisor before sending
