## Template 2 — LinkedIn Post Draft Skeleton

```
Hook line (first 1-2 lines, must stand alone before "see more"):
Body (3-5 short paragraphs or a numbered list, expanding the hook):
Pull-quote or stat from source:
CTA / question to prompt comments:
Link to full piece (in first comment, not post body, per LinkedIn algorithm convention — verify current best practice):
```

## Template 3 — X/Twitter Thread Skeleton

```
Tweet 1 (hook, must work as a standalone tweet):
Tweet 2-N (one idea per tweet, from source piece's sections):
Final tweet: CTA + link to full piece
```

## Template 4 — Instagram Carousel Outline

```
Slide 1: Hook (bold statement or question from source piece)
Slide 2-N: One key point per slide, minimal text, visual-first
Final slide: CTA + "link in bio" or link sticker reference
Caption: expanded hook + 3-5 relevant hashtags
```
