# M10 — Checklists

## Intake Checklist

- [ ] M09 handoff packet received (published URL, pull-quotes, key stat, suggested formats)
- [ ] Repurposing matrix reviewed (`templates.md`) — confirm which formats this piece will be turned into
- [ ] Repurposing tracker row created (Airtable/Notion) so nothing gets missed or duplicated

## Per-Format Drafting QC (applies to every format, every method)

- [ ] Draft matches the tone/rules of the target platform (not just a copy-paste of the blog)
- [ ] No claim in the repurposed piece goes beyond what the source M09 content actually supports
- [ ] No invented stats, quotes, or claims introduced during repurposing — the source piece is the ceiling, not a jumping-off point for embellishment
- [ ] Platform-specific formatting applied (character limits, hashtag conventions, image specs) per the relevant M11-M16 stage's own standards, once those stages are built

## Mandatory Human-Review Gate (before scheduling — non-skippable, all methods)

- [ ] A human who did not generate the AI draft (if applicable) reviews each per-format piece individually
- [ ] Fact-check: every claim traceable back to the source M09 piece
- [ ] Brand voice consistency checked per format
- [ ] Visual assets (carousel slides, quote graphics) reviewed for accuracy and license compliance
- [ ] Video script (if applicable) reviewed for narrative coherence, not just copy-paste of blog headers
- [ ] Email segment reviewed against M17's nurture sequence context (not sent in isolation without knowing where it sits in the sequence)

## Pre-Scheduling Checklist

- [ ] All approved formats logged in the repurposing tracker
- [ ] Approved copy + assets pushed to Postiz (or handed to M17's ESP for the email segment)
- [ ] Scheduling cadence confirmed against each channel stage's own posting schedule (M11-M16) — M10 doesn't set cadence, only supplies content
- [ ] UTM parameters added for tracking (handoff point with M21, once built)

## Post-Distribution

- [ ] Repurposing tracker updated with final scheduled/sent status per format
- [ ] Any format that didn't get repurposed flagged with a reason (not just silently skipped)
