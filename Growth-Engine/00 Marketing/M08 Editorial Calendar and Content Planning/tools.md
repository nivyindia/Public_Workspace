# M08 — Tools

| Tool | Use in M08 | Cost | Notes |
|---|---|---|---|
| Notion (free tier) or Airtable (free tier) | Editorial calendar + backlog home, linked to the M04 keyword tracker | Free tier — verify current record/block caps | Matches the shared tracker pattern used across Track M |
| Google Calendar | Optional lightweight view for publish-date reminders, especially useful if the team already lives in Google Workspace | Free | Not a replacement for the structured Airtable/Notion calendar — a supplementary reminder layer only |
| n8n (self-hosted) | Publish-date reminders, cross-channel sequencing alerts, slipped-deadline flags | Free | See `automation.md` |

## Paid Upgrade Path (optional)

- CoSchedule or a similar dedicated marketing-calendar tool — worth it once the team is large enough that a general-purpose Airtable/Notion base becomes a coordination bottleneck rather than a help.

No paid tool is required to run M08 at pilot depth. This is a coordination stage, not a tool-dependent one — the discipline of maintaining the calendar matters more than the software it lives in.
