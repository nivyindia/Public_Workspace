# M01 — Tools

Pulls from the shared free/OSS stack in `IMPLEMENTATION-PLAN.md` §2, plus stage-specific additions below. All pricing/limits marked "verify current" — free-tier terms change without notice.

## From the Shared Stack

| Function | Tool | Notes |
|---|---|---|
| Reference doc hosting | Notion free tier | Source material for this stage already lives in Notion ("Executive Summary & Company Positioning," "Brand Guidelines") |
| Workflow automation | n8n (self-hosted) | Limited use here — see `automation.md` for why M01 has little to automate |

## Stage-Specific Additions

| Function | Free / OSS tool | Notes | Paid upgrade path |
|---|---|---|---|
| Brand kit / template building | Canva free tier | The existing Brand Guidelines doc already specifies a Canva Brand Kit setup sequence (logo, colors, fonts, then templates for LinkedIn/Instagram/email/proposal) | Canva Pro for premium elements and brand-kit locking across more team seats |
| Logo/icon production | Free options: Canva, or a freelance designer via Fiverr/Upwork for a one-time proper vector logo | The source doc lists 4 required logo versions (primary, dark, icon-only, horizontal) not yet produced | A paid one-off logo design commission if free/DIY tools don't hit professional quality |
| Font sourcing | Google Fonts (free, e.g., Inter, Plus Jakarta Sans, JetBrains Mono — all recommended in the source doc) | Zero cost, no licensing complexity | Licensed premium fonts only if a specific paid typeface is later chosen |
| Stock/original imagery | Unsplash, Pexels (free), Storyset.com, unDraw.co (free illustrations, brand-color matched) | All four already named in the source Brand Guidelines doc as the approved imagery sources | Paid stock libraries only if free sources can't cover a specific need |
| Grammar/consistency check on brand copy | Grammarly free tier | The source doc's own "Brand Don'ts" list explicitly says "never publish content with typos... use Grammarly" | Grammarly Premium for deeper tone suggestions |
| Style-guide distribution | Notion (already in use) or a shared Google Doc | No new tool needed — this stage's output should live wherever the team already checks reference docs | — |

## Notes

- This is the one Track M stage where "which tool" matters far less than "did a human actually make the decision" — no tool here produces the positioning statement, brand voice, or differentiators; tools here only help *execute* decisions already made (build the Canva kit, source the fonts, check the grammar).
- Final brand colors and the 4 logo file versions are marked "action needed" in the source Brand Guidelines doc — verify these have been formally signed off before treating the palette in `templates.md` as locked, not just recommended.
