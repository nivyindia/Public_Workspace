# M04 — Checklists / QC Gates

## Before a keyword enters the Master Tracker

- [ ] Volume checked against at least two sources (e.g., Keyword Planner + Ubersuggest), not one
- [ ] Search intent confirmed by looking at the actual current top-5 SERP results, not guessed from phrasing alone
- [ ] Funnel stage tag derived from confirmed intent, not assigned independently
- [ ] Checked against the existing tracker for duplicate or near-duplicate keyword targeting (cannibalization check)

## Before a keyword is assigned to a URL (M04.5)

- [ ] Confirmed no existing live page already targets this keyword or a close variant
- [ ] Assigned pillar-vs-cluster role is explicit (this keyword is: [ ] the pillar page target / [ ] a cluster article target)
- [ ] Assignment logged with the owning stage (M05 for optimizing an existing page, M09 for a net-new article)

## Before the monthly refresh is marked complete

- [ ] Competitor gap analysis re-run and new competitor topics logged
- [ ] Any keyword whose SERP intent has visibly shifted since last review re-tagged (Google's ranking behavior for a term can change over time)
- [ ] Priority scores recalculated for any keyword with updated volume/difficulty data
- [ ] No keyword left in "needs human review" status from the automated workflow for more than one review cycle
