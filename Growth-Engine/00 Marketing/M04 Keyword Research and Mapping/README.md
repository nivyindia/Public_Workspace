# M04 — Keyword Research & Mapping

**Phase:** B — SEO Engine
**Feeds:** M05 (On-Page SEO Implementation), M08 (Editorial Calendar & Content Planning), M09 (Long-Form Content Production)
**Fed by:** M01 (Brand & Positioning Foundation), M03 (Content Pillars & Messaging Framework)
**Build status:** 🟡 Built to pilot depth this session (Batch 2). No stage-specific raw material doc was located in the connected Google Drive — see `references.md` for what was searched and the gap this leaves.

## Purpose

M04 turns the content pillars defined in M03 into a prioritized, funnel-mapped keyword list — the shared vocabulary every later Track M stage (on-page, technical, content production, editorial calendar) works from. Nothing gets written in M09 or optimized in M05 without a keyword-to-URL assignment traceable back to this stage.

## Inputs

- Brand positioning and ICP definitions (M01)
- Content pillars and messaging framework (M03)
- Existing Google Search Console query data for the domain (if the domain has query history)
- Competitor domain list (from M01/M02 channel selection or supplied directly by the business)

## Outputs

- **Master Keyword Tracker** — every keyword the business is targeting, with search intent, funnel stage, priority score, and assigned URL/content owner
- **Topic cluster map** — pillar pages and their supporting cluster articles
- **Keyword-to-funnel-stage map** — which keywords sit at awareness / consideration / decision, handed to M08 for calendar sequencing

## Sub-Stages

| # | Sub-stage | What it does |
|---|---|---|
| M04.1 | Seed keyword & topic discovery | Generate the raw keyword universe from brand terms, ICP language, and competitor domains |
| M04.2 | Competitor keyword gap analysis | Identify keywords competitors rank for that this domain doesn't |
| M04.3 | Search intent classification | Tag every keyword informational / commercial / transactional / navigational |
| M04.4 | Keyword-to-funnel-stage mapping | Map intent tags to awareness / consideration / decision for M08's calendar |
| M04.5 | Keyword-to-content mapping (pillar/cluster model) | Assign each keyword to an existing or planned URL, preventing duplicate targeting |
| M04.6 | Prioritization & tracking list | Score and rank the final list using volume, difficulty, and business-relevance weighting |

## How This Stage Is Used

1. VA/marketer runs M04.1–M04.2 monthly (or quarterly for a stable niche) to refresh the keyword universe.
2. M04.3–M04.5 are re-run whenever new pillars are added in M03 or new pages ship.
3. The Master Keyword Tracker (`templates.md`) is the single source of truth other stages query — M05 pulls target keywords per page, M08 pulls the funnel-stage tags to sequence the calendar.
