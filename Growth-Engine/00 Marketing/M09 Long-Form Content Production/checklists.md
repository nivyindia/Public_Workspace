# M09 — Checklists

## Pre-Write Checklist

- [ ] Brief pulled from M08 calendar slot (topic, target keyword, audience, content type, word count target)
- [ ] Target keyword confirmed against M04 (Keyword Research & Mapping) — not chosen ad hoc
- [ ] Competitive SERP scan done — top 3-5 ranking pieces reviewed for gaps/angle
- [ ] Outline drafted and approved before full drafting begins

## Drafting QC (applies regardless of method used)

- [ ] Draft matches the approved outline structure
- [ ] Every factual claim has a traceable source (internal doc, own data, or a citable external source)
- [ ] No invented statistics, case studies, or tool claims — per the standing rule in `IMPLEMENTATION-PLAN.md` §6
- [ ] Brand voice/tone consistent with M01 (Brand & Positioning Foundation) once that stage exists — flag for revisit if M01 isn't built yet
- [ ] Readability pass run (Hemingway or equivalent)
- [ ] Grammar pass run (Grammarly free tier or equivalent)

## Mandatory Human-Review Gate (before publish)

This gate applies to **every** piece, regardless of drafting method, and is explicitly non-skippable for AI-assisted or AI-automated drafts per the Implementation Plan's standing QC rule:

- [ ] A human who did not generate the AI draft (if applicable) reads the full piece end-to-end
- [ ] Fact-check pass: every claim verified against a real source, not just plausible-sounding
- [ ] No AI-hallucinated tool names, statistics, quotes, or case studies survive to the reviewed version
- [ ] Legal/compliance flag raised for any claim touching pricing, guarantees, or regulated topics
- [ ] SEO on-page elements checked (title tag, meta description, header structure) — handoff point with M05
- [ ] Internal links added to relevant existing content
- [ ] Featured image sourced and licensed correctly (Unsplash/Pexels license terms honored)

## Pre-Publish Final Check

- [ ] URL slug finalized and matches keyword strategy
- [ ] All links tested (no 404s, no placeholder links left in)
- [ ] Mobile rendering spot-checked
- [ ] Piece logged as "Ready for M10" with excerpt/pull-quotes flagged for repurposing

## Post-Publish

- [ ] Published URL and excerpt handed off to M10 intake
- [ ] M08 calendar row updated to "Published"
- [ ] Analytics tagging confirmed (GA4 goal/UTM structure per M21, once built)
