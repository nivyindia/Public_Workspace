# M09 — Long-Form Content Production

**Phase:** C — Content Engine
**Status:** ✅ Built to pilot depth (2026-07-22)
**Feeds into:** M10 (Content Repurposing & Distribution Engine), which fans this stage's output out to M11–M17 (social channels + email)
**Upstream input from:** M08 (Editorial Calendar & Content Planning) — this stage produces what M08 schedules

---

## 1. What This Stage Covers

M09 is where a calendar slot from M08 becomes an actual piece of long-form content: a blog post, pillar page, whitepaper, case study, or long-guide. It is deliberately scoped to **long-form written content only** — turning that content into social posts, email sends, or video is M10's job, not this stage's. Keeping the line there means M09's files stay focused on writing craft and QC, and M10's stay focused on repurposing mechanics.

## 2. Sub-Stages

1. **Brief intake** — pull the topic, target keyword, audience, and content type from the M08 calendar slot.
2. **Research & outline** — competitive SERP scan, source gathering, outline draft.
3. **Drafting** — manual, AI-assisted, or hybrid draft (see `methods.md`).
4. **Human review & fact-check QC gate** — mandatory before anything moves to M10 (see `checklists.md`).
5. **On-page SEO pass** — handoff/overlap point with M05 (On-Page SEO Implementation); M09 owns the writing, M05 owns the on-page technical implementation once the draft is final.
6. **Publish** — goes live on owned property (blog/site).
7. **Handoff to M10** — published URL + key excerpts passed to the repurposing engine.

## 3. Why This Was the Pilot

Per `IMPLEMENTATION-PLAN.md` §3, M09 (paired with M10) was chosen as the pilot because your existing Content Marketing Calendar and the "Content Repurposing System" material already documented in the Social Media Playbooks doc gave this pair the strongest existing raw material to build from, and because M10's output is the shared input every social/email stage downstream depends on.
