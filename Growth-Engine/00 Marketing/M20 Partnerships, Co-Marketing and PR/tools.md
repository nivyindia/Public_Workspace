# M20 — Tools

Pulls from the shared free/OSS stack in `IMPLEMENTATION-PLAN.md` §2, plus stage-specific additions below. All pricing/limits marked "verify current" — free-tier terms change without notice.

## From the Shared Stack

| Function | Tool | Notes |
|---|---|---|
| CRM (partner + inbound bridge target) | Odoo or SuiteCRM | Named directly in the shared stack; the Active Partner Tracker and PR coverage log can live here or alongside it in Airtable/Notion |
| Workflow automation | n8n (self-hosted) | Powers partner-onboarding and reward-notification automation in `automation.md` |
| Experiment tracking | Airtable free tier or Notion free tier | For the Active Partner Tracker and media list in `templates.md` |

## Stage-Specific Additions

| Function | Free / OSS tool | Notes | Paid upgrade path |
|---|---|---|---|
| Formal affiliate program platform (Method 5) | Manually tracked spreadsheet/Airtable base for early volume | No dedicated free-tier affiliate platform is assumed here — this is flagged rather than defaulted to a specific paid tool | Tapfiliate, ReferralHero, or similar dedicated affiliate platforms once volume justifies the cost (named in the existing internal Affiliate & Referral Program Setup doc as the reference options) |
| Media/journalist list building | Manual research via publication mastheads, podcast guest pages, and journalist social profiles (free) | Enough for a 20–50 contact media list at SMB scale | Paid media database tools (Muck Rack, Cision) once PR volume justifies |
| Press release distribution | Direct outreach to the built media list (free) | No distribution-service cost needed for a targeted, researched list | Paid wire distribution services if broad, non-targeted reach is ever needed |
| Partner agreement documents | Google Docs (free) | The simple partner agreement template in `templates.md` needs no dedicated contract tool | E-signature tools (DocuSign, PandaDoc) once formal SLA agreements (Method 3/Platinum tier) are common enough to justify |
| Webinar hosting (co-marketing) | Google Meet or Zoom free tier | Zoom free tier time-caps group calls — verify current limit | Zoom paid tier or a dedicated webinar platform for larger co-marketing events |

## Notes

- No tool in this list requires a paid tier to run Methods 1–4 end-to-end.
- Method 5 (formal affiliate program) is the one sub-method where a paid platform is realistically the better path once volume justifies it — this is flagged explicitly rather than defaulting to a "free-first" recommendation that would create more manual tracking overhead than it saves.
