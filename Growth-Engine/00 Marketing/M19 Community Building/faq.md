# M19 — FAQ

**Q: Is this the same as the internal growth-execution community described in the "Community of Growth Engine" doc (departments, leaders, commission tiers)?**
No, and this distinction is worth being explicit about. That doc describes a paid internal workforce structure — people doing content, referrals, and outreach in exchange for commission, organized into departments with leaders. That's an operations/resourcing model for getting execution done without hiring, not a Track M marketing-funnel stage. M19 is about building an owned community *of your ICP* (prospects and clients), where the goal is trust and brand proximity, not task execution. The two concepts share some mechanics (referral leaderboards, phased rollout) which is why this stage's `resources.md` cites the doc — but M19 doesn't adopt its department/commission structure wholesale.

**Q: Which platform should we start with?**
Whichever one the ICP already uses for similar communities — see the worksheet in `templates.md`. The shared free/OSS stack in `IMPLEMENTATION-PLAN.md` §2 names WhatsApp and Discord as fitting the likely ICP channels, but that's a starting assumption to validate, not a fixed decision.

**Q: How big should the community be before we start promoting it broadly?**
There's no fixed number — the signal to watch for is members replying to each other, not just to the founder (see Method 2 in `methods.md`). Promoting an empty or founder-only-active room does more harm than good.

**Q: Can we automate the welcome and engagement prompts?**
Yes, partially — see `automation.md`. Welcome messages and scheduled prompts automate well. Buying-intent detection and the actual relationship-building (founder replying, following up with new members) stay manual, especially in the Phase 1 seeding window.

**Q: How do community leads get into the sales pipeline?**
Through the same M22 Inbound-to-CRM Bridge every other Track M stage uses — a moderator flags buying-intent activity, logs it with source = "Community," and it follows the same inbound record structure into Sales Funnel Stage 06.

**Q: What if we don't have a validated offer yet — should we build the community anyway?**
No — this is the one hard "don't" carried over from the source material. A community without something real behind it becomes noise rather than a growth asset.
