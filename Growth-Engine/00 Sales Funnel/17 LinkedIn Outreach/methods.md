# Methods — 17 LinkedIn Outreach

[⬅ Back to README](README.md)

## Traditional
Manual profile browsing and personally sent connection requests/messages — used for high-value named accounts.

## Modern / Tool-Assisted
Sales Navigator for advanced search/filtering; PhantomBuster for semi-automated connection and DM sending within daily limits.

## AI-Assisted
LLM-drafted connection notes and DM copy variants; LLM summarization of a prospect's recent posts/activity for personalization.

## Manual
Personally reviewing and sending to strategic named accounts; manually handling nuanced replies.

## Automated
PhantomBuster/n8n executing the daily connection-request and DM-sequence cadence within safe limits, once a target list is loaded.

## API / Integration
LinkedIn does not offer a public outreach API for third parties (Sales Navigator has a limited official API for enterprise integrations); most automation uses browser-session-based tools, which carries account-risk trade-offs to weigh against volume gained.

## Browser Automation
PhantomBuster and similar tools drive connection requests/DMs via a logged-in session — the dominant automation method for this stage, used within conservative daily limits to avoid detection.

## Scraping
Sales Navigator search exports (via PhantomBuster) feed the target list; no direct scraping of LinkedIn beyond what these sanctioned-use tools provide.

## Public Database / Government
Not applicable to this stage.

## Community / Referral
Warm intros from mutual connections can enter directly at the DM stage without a cold connection request, referencing the mutual contact.

## Method Selection Guidance
Use browser-automation tools for volume, strictly within daily limits; reserve fully manual outreach for named strategic accounts where a templated note would read as impersonal.
