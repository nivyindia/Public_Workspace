## Solution Map Document Template

```
Opportunity: [Company / Contact]
Source: Needs Analysis dated [date]

Problem #1 (Rank 1): [restated from needs analysis]
  Deliverable(s): [specific service/deliverable that addresses this]
  Expected Outcome: [tied to their stated desired outcome]

Problem #2 (Rank 2): [...]
  Deliverable(s): [...]
  Expected Outcome: [...]

Recommended Package: [Standard package name] OR [Customized scope — see below]

Customization Required: [Yes/No]
  If Yes — Reasoning: [why the standard catalog doesn't fully fit]
  Internal Sign-Off: [name, date]

Matched Case Studies:
  1. [case study name] — relevant because [reason]
  2. [case study name] — relevant because [reason]

Status: [Draft / Reviewed / Approved]
```

## Package Fit Decision Guide
- **Standard package fits** if the ranked problems map cleanly to an existing package's deliverables without needing anything outside its scope
- **Customization warranted** if a genuinely important ranked problem falls outside every standard package's scope — not just because the prospect asked for something extra
