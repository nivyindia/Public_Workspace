# Methods — 22 Personalization and Copywriting

[⬅ Back to README](README.md)

## Traditional
A rep hand-writes each message from scratch, drawing on personal judgment of tone and relevance.

## Modern / Tool-Assisted
A documented style guide plus merge-field templates (Stages 16-21) that reps/VAs fill in per contact.

## AI-Assisted
LLM-drafted Tier-2/Tier-3 personalization lines from enrichment data; LLM-assisted copy variant generation for A/B testing.

## Manual
Human review/approval of any new template before it goes live at volume; hand-writing for named strategic accounts.

## Automated
Bulk Tier-1 merge-field population (name, company) via the sequencer/CRM tools already used in Stages 16-20.

## API / Integration
Enrichment data (Stage 08) feeding personalization fields via CRM integration, so copy tools pull live data rather than stale manual entry.

## Browser Automation
Not applicable directly to this stage; upstream enrichment (Stage 08) may use browser automation to gather the signals this stage personalizes against.

## Scraping
Not used directly; personalization signals come from Stage 08 enrichment, not fresh scraping at this stage.

## Public Database / Government
Not applicable to this stage.

## Community / Referral
Referral-sourced contacts justify a Tier-3 personalization line referencing the mutual connection directly, which is usually the strongest-performing personalization available.

## Method Selection Guidance
Use AI-assisted drafting for Tier-2 personalization at scale; reserve human-written Tier-3 lines for high-value contacts where enrichment data supports a genuinely specific detail worth referencing.
