# Checklists — 53 Referral Programs

[⬅ Back to README](README.md)

## Program Setup QC
- [ ] Commission/incentive structure documented and consistent across all referrers
- [ ] Tracking mechanism (platform or built-in codes) tested before launch
- [ ] Launch communication sent to existing client base

## Referral Ask QC
- [ ] Asks made to genuinely satisfied (promoter-flagged) clients, not blanket-sent
- [ ] Message personalized to the client's specific context, not a generic blast

## Tracking & Attribution QC
- [ ] Every referred contact tagged with the correct referrer tracking code
- [ ] No referral attribution lost between the ask and the contact entering the funnel

## Payout QC
- [ ] Payouts processed only on Closed Won status, per the documented structure
- [ ] Payout amounts match the program's commission terms exactly

## Duplicate / Accuracy / Completeness Checks
- [ ] No referred contact double-attributed to two different referrers
- [ ] No referral tracking code reused across different clients
