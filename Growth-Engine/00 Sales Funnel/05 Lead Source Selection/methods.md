# Methods — 05 Lead Source Selection

> Part of Stage 05 (Lead Source Selection). See [README.md](README.md) for the full stage overview.

---

## Fit-Mapping Methods

- **ICP-to-source coverage matching** — cross-reference each active ICP's role/size/geography against what each source actually covers well (e.g. Apollo strong for US/UK/AU/UAE SMEs; JustDial/IndiaMART for India; Companies House for UK company data by SIC code; ABR for Australian business data)
- **Prior-campaign performance review** — before choosing a source for a new campaign, check the source-performance log for how that source has performed for a similar ICP/market before

## Cost/Volume Tradeoff Methods

- **Cost-per-qualified-lead calculation** — for paid sources, divide tool cost by the number of leads that actually passed Stage 11 scoring, not just the raw pull count
- **Free-source-first testing** — where a free/low-cost source (Google Maps, Companies House, JustDial) plausibly covers the ICP, test it before committing budget to a paid database

## Compliance-Check Methods

- **Market-specific data rule review** — confirm contact method and data handling comply with the target market's rules before scaling (e.g. GDPR in UK/EU requires legitimate business interest basis and an unsubscribe option)

## Pilot-Test Methods

- **Small-batch test extraction** — pull a small sample (e.g. 20-50 leads) from a newly-considered source and run it through Stage 06-11 before committing to full volume

## AI-Assisted Methods

- LLM-recommended source shortlist per ICP/market combination (see [README.md §7](README.md#7-ai-section))
- AI-summarized source-performance review with keep/rotate/drop recommendations
