# 05. N8N BUILDING RULES

For every n8n workflow:

### 5.1 Trigger

Use the trigger specified by the Master Plan.

Possible triggers include:

* Webhook
* Schedule
* Cron
* Manual trigger
* Odoo event/API
* Database-driven trigger
* External application webhook
* Sub-workflow execution

Do not replace a specified trigger without documenting why.

---

### 5.2 Input validation

Every externally triggered workflow should validate:

* Required fields
* Data types
* IDs
* Email addresses
* Phone numbers
* Dates
* Amounts
* Status values
* Authentication/security fields

Invalid input should fail safely.

---

### 5.3 Normalize data

Normalize external inputs before business logic.

Examples:

```text
email → lowercase
phone → E.164 where applicable
IDs → string/integer according to schema
timestamps → UTC/defined project standard
currency → explicit currency code
status → canonical status
```

---

### 5.4 Idempotency

Any workflow that can be triggered more than once must consider idempotency.

Examples:

* Webhook retries
* Payment callbacks
* WhatsApp callbacks
* Email events
* Proposal acceptance
* Contract callbacks
* CRM synchronization

Never create duplicate records simply because the same event was delivered twice.

# 18. HMAC IMPLEMENTATION

Environment variable:

```text
PROPOSAL_ACCEPT_HMAC_SECRET
```

Never hard-code the secret.

Token format:

```text
lead_id.expiry_unix.signature
```

Signature:

```text
HMAC-SHA256
```

The token must not be trusted until:

```text
signature valid
AND
expiry valid
```

Use timing-safe comparison for signatures.

---

# 19. REPLAY PROTECTION

HMAC verification alone does **not** provide true one-time-use replay protection.

For workflows requiring one-time acceptance:

```text
Verify token
      ↓
Check token/event consumption state
      ↓
Atomically mark consumed
      ↓
Continue
```

The database operation must prevent two simultaneous requests from both consuming the same token.

Do not claim replay protection is complete until persistent one-time-use state exists.
