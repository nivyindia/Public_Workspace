## QC-004 — Report Quality Checklist

### Before Submitting:

- [ ]  All fields in the daily report are filled (no blank cells)
- [ ]  "New leads added" matches the number of new rows in CRM today
- [ ]  "Outreach messages sent" matches the actual count (pulled from platform or CRM, not estimated)
- [ ]  "Replies received" matches actual replies across all platforms today
- [ ]  Reply rate calculated correctly: (Replies ÷ Messages Sent × 100)
- [ ]  Booking rate calculated correctly: (Calls Booked ÷ Positive Replies × 100) — enter "N/A" if no positive replies
- [ ]  Blockers field is completed (write "None" if none — blank is not acceptable)
- [ ]  Tomorrow’s plan is filled in (3 fields: lead target, message target, priority task)
- [ ]  Report is being submitted by or before 6:00 PM

### Accuracy Check:

- [ ]  Numbers match CRM data — if there’s a discrepancy, update CRM first, then report
- [ ]  No rounding or inflating of numbers (e.g. "around 20 messages" is not acceptable)

---

**A daily report is your professional record. Inaccurate numbers now create problems in the weekly scorecard later. Be precise.**
