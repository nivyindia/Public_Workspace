## Escalation Rule

1. If a VA makes the same error twice → retrain using relevant SOP
2. If a VA makes the same error three times → escalate to Manager
3. If system issue (not person issue) → log in System Feedback Log

Do not skip the log. Patterns only become visible when documented.
