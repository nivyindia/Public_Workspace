# 🗺️ Customer Journey Overview

This document maps the full customer lifecycle across **5 stages**, with automation triggers and actions defined for each phase using n8n.

| Stage | Phase | Goal | Automation Tool |
| --- | --- | --- | --- |
| 1 | 🧲 Awareness | Capture leads | n8n + Meta/Google Ads webhook |
| 2 | 💡 Consideration | Nurture & educate | n8n + Email sequence |
| 3 | 🤝 Conversion | Book & close | n8n + CRM + Calendar |
| 4 | 🛠️ Onboarding | Deliver value fast | n8n + Notion + Slack |
| 5 | 🔁 Retention | Upsell & referrals | n8n + Review requests |
