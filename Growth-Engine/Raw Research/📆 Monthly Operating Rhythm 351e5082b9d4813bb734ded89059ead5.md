# 📆 Monthly Operating Rhythm

Monthly cadence. Three phases: Start of month, mid-month, end of month.

---

## Start of Month (Day 1–3)

- [ ]  Review last month's full performance data
- [ ]  Set this month's team targets (outreach volume, bookings, conversion rate)
- [ ]  Review VA progression: who advanced, who is stuck, who is at risk?
- [ ]  Update Salary & Incentive Structure if any changes apply
- [ ]  Run Monthly Audit Checklist
- [ ]  Update System Health Dashboard — set the month's health baseline

---

## Mid-Month (Day 14–16)

- [ ]  Check actual vs target metrics at the halfway point
- [ ]  Adjust targets if business conditions have changed (document the reason)
- [ ]  Identify VAs needing extra support to hit monthly target
- [ ]  1:1 with Supervisor: team morale check, any emerging issues?
- [ ]  Review System Feedback Log: any recurring system issues to resolve?

---

## End of Month (Day 28–31)

- [ ]  Compile full monthly metrics report
- [ ]  Review all VA scorecards: who is green / amber / red?
- [ ]  Make progression decisions: advances, holds, pip (if needed)
- [ ]  Run Dispute & Grievance Process review: any open cases?
- [ ]  Submit monthly report to leadership/founder
- [ ]  Plan next month: targets, focus, any hiring or training needs
- [ ]  Archive this month's System Feedback Log entries
