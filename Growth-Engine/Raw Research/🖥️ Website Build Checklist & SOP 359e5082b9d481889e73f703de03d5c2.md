# 🏗️ PLATFORM DECISION {#platform}

| Option | Pros | Cons | Recommended For |
| --- | --- | --- | --- |
| **WordPress + Astra** | Full control, plugin ecosystem, free | Requires hosting, maintenance | Best choice for Nivy ✅ |
| **Webflow (free tier)** | Beautiful, no-code, fast | Limited pages on free tier | Good alternative |
| **Framer** | Modern, fast | Less SEO control | Design-focused sites |

**✅ Recommended:** WordPress + Astra theme + Hostinger/SiteGround hosting (~₹200/month)

# 📄 PAGE-BY-PAGE BUILD GUIDE {#pages}

## 🏠 Home Page

**Purpose:** Convert visitors into leads in under 10 seconds

| Section | Content Needed | CTA |
| --- | --- | --- |
| Hero | Headline + sub-headline + hero image | "Book Free Strategy Call" button |
| Trust Bar | Client logos OR stats (50+ clients, 3 countries) | — |
| Services Overview | 3–4 service cards with icons | "Learn More" per card |
| How We Work | 3-step visual process | — |
| Client Results | 3 mini case study cards with numbers | "See All Case Studies" |
| Testimonials | 3–5 rotating client quotes with photos | — |
| Bottom CTA | "Ready to grow?" section | "Book Your Free Call" → [Cal.com](http://Cal.com) |
| AI Chat Widget | Chatwoot/Tidio floating widget | Auto-greeting |

## 🛠️ Services Page (one per service)

- **VA Services** — What VAs do, how to hire, pricing tiers, FAQ accordion
- **Digital Marketing** — Services list, process, results, FAQ
- **AI & Automation** — Use cases, tech stack, FAQ
- **Lead Generation** — How it works, deliverables, FAQ

## 📁 Case Studies / Portfolio Page

- 3–5 detailed case studies
- Structure per case study: **Challenge → Solution → Results (with numbers)**
- Sector logos: Roofing, Real Estate, E-commerce, SaaS

## 📝 Blog Page

- Archive page showing all posts
- Category filters (VA Tips, Marketing, Automation, Business Growth)
- Each post: featured image, author, date, read time, social share buttons
- Sidebar: lead capture form + related posts

## 📞 Contact Page

- HubSpot form (Name, Email, Phone, Company, Service Interest, Message)
- [Cal.com](http://Cal.com) booking embed ("Book a 30-min strategy call")
- WhatsApp click-to-chat button
- Office location (Lucknow, UP, India)
- Response time promise: "We respond within 4 business hours"

## ❓ FAQ Page

- Accordion-style Q&A (20+ questions minimum)
- Categories: General, Pricing, Process, VA Services, Marketing
- Feed these into chatbot knowledge base

# ⚙️ TECHNICAL SETUP CHECKLIST {#technical}

## SEO Setup

- [ ]  Rank Math SEO plugin installed and configured
- [ ]  XML sitemap generated and submitted to Google Search Console
- [ ]  Robots.txt file configured correctly
- [ ]  All pages have unique meta title + description
- [ ]  Schema markup on Home, Services, FAQ pages
- [ ]  Local SEO schema: Business name, address, phone, hours

## Speed & Performance

- [ ]  WP Rocket or LiteSpeed Cache plugin installed
- [ ]  Images compressed (use WebP format)
- [ ]  CDN enabled (Cloudflare free tier)
- [ ]  Google PageSpeed score: Target 80+ on mobile

## Analytics & Tracking

- [ ]  Google Analytics 4 tracking code installed
- [ ]  Microsoft Clarity installed (free heatmaps + session recordings)
- [ ]  Google Search Console verified
- [ ]  HubSpot tracking code installed
- [ ]  Goal/conversion tracking set up in GA4 (form submissions, call bookings)

## Security

- [ ]  Wordfence Security plugin installed
- [ ]  Login URL changed from /wp-admin (security)
- [ ]  Automatic backups enabled (UpdraftPlus free)
- [ ]  Two-factor authentication on WordPress admin
