# 🗓️ Weekly Review Process

**Every Monday morning:**

1. Pull last week’s KPIs from HubSpot + Apollo + GA4
2. Fill in the weekly tracker (or review VA reports)
3. Identify any metric below target — root cause and fix
4. Set targets for the coming week
5. Share summary with the team in Slack/WhatsApp

---

# 📈 Monthly KPI Review

At end of each month:

- Compare actuals vs. targets
- Calculate MRR growth %
- Review top-performing VAs
- Adjust targets for next month
- Update the master plan if strategy changes
