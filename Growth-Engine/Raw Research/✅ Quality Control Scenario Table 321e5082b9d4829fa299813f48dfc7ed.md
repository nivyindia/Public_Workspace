# ✅ Quality Control Scenario Table

# QC System Master Summary

## 1. Overall QC Flow

| Step | Action | Owner | Output |
| --- | --- | --- | --- |
| 1 | Daily audit (10–20 leads per VA) | QC | Errors + Scores |
| 2 | Fill Criteria Scoring Sheet | QC | Exact score per VA |
| 3 | Log mistakes in Error Log | QC | Raw error data |
| 4 | Weekly summary | Supervisor | Total errors + trends |
| 5 | Identify Top 3 mistakes | Supervisor/QC | Focus areas |
| 6 | Micro training | Trainer | Skill improvement |
| 7 | Track improvement | QC | Performance change |
| 8 | Leaderboard + Salary | Admin | Rewards / penalties |

## ⚠️ Critical Override Penalties

| Scenario | Impact |
| --- | --- |
| Fake sheet work | Score = 0 (day invalid) |
| Ignored hot lead | -5 |
| Spam / account risk | -5 to -10 |
| Repeated negligence | Escalation |

---

## 🎯 Bonus System (Daily Cap: +5)

| Action | Bonus |
| --- | --- |
| High-quality reply | +1 |
| Qualified lead | +2 |
| Meeting booked | +3 |
| Deal closed | +5 |

---

## 📈 Final Score Calculation

**Final Score = Sum of all category scores − Penalties + Bonus (max +5)**

## 3. Error Log System

| Field | Description |
| --- | --- |
| Date | When checked |
| VA Name | Who made error |
| Category | Targeting / Messaging / etc |
| Error Type | Specific mistake |
| Severity | Minor / Moderate / Major |
| Count | Number of occurrences |

---

## 4. Top 3 Mistake System

| Step | Rule |
| --- | --- |
| Identify | Pick highest frequency errors |
| Limit | Only Top 3 per VA |
| Focus | Ignore all other mistakes |
| Train | Only those 3 mistakes |
| Recheck | Compare weekly |

Example:

| Rank | Mistake | Count |
| --- | --- | --- |
| 1 | No Personalization | 15 |
| 2 | Wrong Industry | 8 |
| 3 | Poor English | 6 |
