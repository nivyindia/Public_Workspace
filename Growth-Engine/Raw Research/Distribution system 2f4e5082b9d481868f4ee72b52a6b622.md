# 2. LEVEL-WISE CRITERIA STRUCTURE (CLEAR & STRICT)

We’ll define **4 levels**:

1. Outlet Partner
2. Senior Outlet / Lead Outlet
3. City Master Partner
4. State Master Partner

---

## LEVEL 1: OUTLET PARTNER (ENTRY LEVEL)

### Who can apply

- Cyber café
- GST / ITR shop
- Printing / documentation shop
- Mobile / AEPS shop

### Minimum Criteria

| Category | Requirement |
| --- | --- |
| Business | Existing shop (6+ months) |
| Knowledge | Basic GST / ITR awareness |
| Infrastructure | Laptop, scanner, internet |
| Time | 4–6 hrs/day availability |
| Trust | Local presence + repeat customers |

### Knowledge Check (must pass)

They should be able to answer:

- What is GST?
- What is ITR?
- Difference between Proprietorship & Company
- Basic document list awareness

👉 **No technical expertise needed**

## LEVEL 2: SENIOR OUTLET / LEAD OUTLET

- Local guidance
