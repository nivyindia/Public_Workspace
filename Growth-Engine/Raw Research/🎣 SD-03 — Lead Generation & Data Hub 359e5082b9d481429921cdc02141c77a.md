# 🔧 LEAD SCRAPING SYSTEMS & TOOLS {#scraping}

## Tool Stack

| Tool | Use Case | Cost | Notes |
| --- | --- | --- | --- |
| [**Apollo.io**](http://Apollo.io) | B2B contact database, email finder | Free (50 exports/mo) | #1 tool |
| **LinkedIn Sales Navigator** | Advanced prospect search | Free trial / $79/mo | Use for high-value targets |
| **PhantomBuster** | LinkedIn automation & scraping | Free tier (20 actions/day) | Connect + DM automation |
| [**Hunter.io**](http://Hunter.io) | Email finder from domain | Free (25/mo) | Verify emails |
| [**Snov.io**](http://Snov.io) | Email finder + outreach | Free tier | Alternative to Apollo |
| **Apify** | Web scraping (custom) | Free tier | For custom data sources |
| **Google Maps Scraper** | Local business leads | Free (via Apify) | India + international |

## How to Build a Lead List (Step-by-Step)

1. Define ICP: industry + company size + location + title (from SD-02)
2. Open [Apollo.io](http://Apollo.io) → People Search
3. Filters: Title ("Founder", "CEO", "Director") + Industry + Location + Company size (1-50)
4. Export up to 50 emails/month on free plan
5. Verify emails with [Hunter.io](http://Hunter.io) (avoid bounces)
6. Import to HubSpot CRM as new contacts
7. Tag: `apollo-outbound` + `[campaign-name]`
8. Hand off to SD-04 Outbound for sequencing

# 👤 LINKEDIN LEAD MINING {#linkedin-leads}

## Method 1: Boolean Search (Free)

```
Search: "CEO" OR "Founder" OR "Director" "virtual assistant" OR "operations" -"looking for work"
Filter by: Location (US/UK/India), Industry, Connection degree
```

## Method 2: Sales Navigator Searches

- Company headcount: 1-50
- Seniority: Owner, CXO, Director
- Geography: United States, United Kingdom, UAE
- Industry: Real Estate, Technology, E-Commerce, Consulting

## Method 3: PhantomBuster Automation

1. Set up PhantomBuster LinkedIn Search Export
2. Input search URL from LinkedIn
3. Run daily (20 profiles/day on free)
4. Export to Google Sheets → n8n picks up → HubSpot entry
