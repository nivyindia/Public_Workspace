# 🔎 OVERVIEW {#overview}

You can't manage what you don't measure. SD-09 ensures every lead, every deal, every VA activity is tracked, scored, and visible in one dashboard. The goal: no lead falls through the cracks; every week starts with a clear picture of pipeline health.

# 🗄️ HUBSPOT CRM SETUP SUMMARY {#hubspot}

## Contact Properties to Track

| Property | Type | Notes |
| --- | --- | --- |
| Name / Email / Phone | Standard | Required on all leads |
| Company & Country | Standard | Required |
| Lead Source | Dropdown | website / chatbot / LinkedIn / WhatsApp / directory / referral |
| Service Interest | Dropdown | VA / Marketing / Automation / Multiple |
| Lead Score | Numeric | Auto-calculated (behavior-based) |
| Last Activity Date | Date | Auto-updated |
| Assigned Sales Rep | User | Default: Founder |
| Market | Dropdown | India / US / UK / UAE / Australia / Other |

## Lead Scoring Rules

| Behavior | Score |
| --- | --- |
| Visited pricing page | +15 |
| Downloaded lead magnet | +20 |
| Opened 3+ emails | +10 |
| Booked discovery call | +30 |
| Replied to outreach | +25 |
| Chatbot conversation | +10 |
| From target country (US/UK/UAE/AU) | +15 |

**Score ≥ 50 → Immediate Slack alert to founder**

**Score ≥ 80 → Priority deal, same-day follow-up required**
