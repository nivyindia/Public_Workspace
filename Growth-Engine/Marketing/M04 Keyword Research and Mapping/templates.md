# M04 — Templates

## 1. Master Keyword Tracker (Airtable/Notion columns)

| Column | Type | Notes |
|---|---|---|
| Keyword | Text | The exact phrase |
| Search Volume (tier) | 1–5 | Derived from Keyword Planner range / Ubersuggest |
| Difficulty (tier) | 1–5 | Judgment-based, cross-checked against SERP competition |
| Business Relevance (tier) | 1–5 | Set by business owner/marketer — not tool-derived |
| Priority Score | Formula | `(Relevance × Volume) / Difficulty` |
| Search Intent | Select | Informational / Commercial / Transactional / Navigational |
| Funnel Stage | Select | Awareness / Consideration / Decision (derived from Intent) |
| Assigned Pillar | Link | Links to the M03 pillar this keyword supports |
| Assigned URL | Link/Text | Existing page URL, or "New — see M09 brief #___" |
| Status | Select | Needs Review / Confirmed / Assigned / Live |
| Last Reviewed | Date | For the monthly-refresh checklist |
