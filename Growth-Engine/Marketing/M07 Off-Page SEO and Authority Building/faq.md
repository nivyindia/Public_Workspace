# M07 — FAQ

**Q: How is M07 different from M20 (Partnerships, Co-Marketing & PR)?**
There's real overlap — a guest post or PR placement builds both a relationship (M20's focus) and a backlink (M07's focus). Track the relationship/partnership side in M20 and the resulting link in M07's backlink tracker; don't duplicate the same activity as two separate line items in two separate trackers.

**Q: Can we just buy backlinks to speed this up?**
No — this is a standing rule in `methods.md`, not a preference. Purchased links and link schemes violate Google's link spam policies and risk a manual action that can suppress the entire domain's rankings, which is a far worse outcome than slow organic growth.

**Q: How long does off-page authority building take to show results?**
Meaningfully longer than on-page or technical fixes — months, not days, is the realistic expectation, and this should be set clearly with stakeholders so M07 isn't judged against the same timeline as, say, an M06 technical fix.

**Q: Do we need Ahrefs or SEMrush to do this properly?**
Not for pilot-depth execution — Search Console's own Links report is the authoritative source for the domain's own backlink profile, and free-tier backlink checkers are enough for competitor-gap prospecting at SMB scale. A paid tool becomes worth it once outreach volume and competitive intensity justify deeper analysis.

**Q: What counts as a "toxic" link that might need disavowing?**
A clear, documented pattern — not a single unfamiliar domain. Isolated odd-looking links are common and usually harmless; only a genuine pattern (bulk, clearly-purchased-looking, or actively flagged by Search Console) warrants the disavow step, per the standing rule in `methods.md`.
