# M03 — Content Pillars and Messaging Framework

**Phase:** A — Foundation
**Status:** ✅ Built to pilot depth (2026-07-23)
**Feeds into:** M09 (Long-Form Content Production) as structured input — every brief M09 drafts against should trace back to one of the pillars defined here, not be picked ad hoc per piece. M08 (Editorial Calendar) also schedules against these pillars to keep coverage balanced across topics.
**Upstream input from:** M01 (Brand & Positioning Foundation) — pillars are themed applications of the voice and positioning already defined there, not a separate messaging system.

---

## 1. What This Stage Covers

M03 is a decision-layer stage (mostly 🔴, strategic) that answers: what are the recurring themes every piece of content, regardless of channel, should map back to? It is deliberately scoped to **defining the pillars and the messaging framework**, not producing content against them — that's M09/M10's job for long-form and repurposed content, and M11–M17's job for channel-native posts.

## 2. Sub-Stages

1. **Pillar identification** — the 3–5 recurring topic themes Nivy Digital content should consistently cover
2. **Pillar-to-keyword mapping** — a target keyword or search intent per pillar, so M04 (Keyword Research) and M09 (Content Production) have a clear starting point per pillar
3. **Pillar-to-content-type mapping** — which formats (blog, case study, video, newsletter section) each pillar is best expressed through
4. **Messaging framework** — headline options, elevator pitch, and CTA set that content built under any pillar should stay consistent with
5. **Pillar balance check** — a light rule of thumb for how often each pillar should appear in the content mix, so one pillar (e.g., case studies) doesn't crowd out the others

## 3. Why This Was Built the Way It Was

Per `IMPLEMENTATION-PLAN.md` §4 (Batch 1), this stage mines existing internal material rather than writing pillars from scratch: the Content Pillars table already defined inside the "SD-05 — Inbound Marketing Hub" doc (VA Services, Digital Marketing, Automation, Client Success — each with a target keyword and content types), the "What We Do" 5-service breakdown and Core Messaging section from "Executive Summary & Company Positioning," and the Email Content Pillars table from the "Email Newsletter System" doc (which independently arrived at a similar but not identical pillar set for the newsletter specifically). This stage reconciles those into one consistent framework rather than letting each channel invent its own pillar language.

## 5. What's Not Built Yet

This stage reconciles pillar language across the source docs but does not yet include a real historical content audit (which existing published pieces map to which pillar, and is the current mix actually balanced) — that requires M08's calendar and M09's actual publishing history to exist first. The pillar balance guidance in `checklists.md` is a starting rule of thumb, not yet validated against real publishing data.
