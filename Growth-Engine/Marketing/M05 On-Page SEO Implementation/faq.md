# M05 — FAQ

**Q: Should every page target only one keyword?**
One *primary* keyword per page, plus naturally-supporting secondary terms from the same M04 cluster. Trying to rank one page for two unrelated primary keywords usually means it ranks weakly for both — that's a signal to split into two pages instead.

**Q: How long should a title tag be?**
Long enough to include the keyword and read naturally, short enough not to truncate in the SERP — check with a snippet-preview tool rather than relying on a fixed character count, since Google truncates by pixel width, not character count, and that behavior isn't fixed forever.

**Q: What if a page already ranks reasonably well — should we still run it through M05?**
Yes, but as a lighter re-optimization pass (check the checklist for gaps) rather than a full rewrite. Don't disturb a page that's already performing without a clear reason.

**Q: Is keyword density (X% of the text) still a real ranking factor?**
Treat it as outdated guidance — current best practice is natural, reader-first writing that covers the topic thoroughly, not hitting a keyword-percentage target. Forcing density tends to produce worse content and is explicitly flagged against in `methods.md`.

**Q: Who signs off on a page going live — the VA doing the optimization, or someone else?**
Per the standing QC-gate rule (IMPLEMENTATION-PLAN.md §6), a named human sign-off is required before publish; whether that's the VA themselves or a reviewing marketer depends on team size, but it must be an explicit, logged step, not assumed.
