# International B2B Marketing Knowledge Base — Marketing Funnel (Track M)

Enterprise-grade, modular, version-controlled documentation of the full 22-stage Marketing / Demand-Generation Funnel — from Brand Foundation through Inbound-to-CRM Bridge. Designed as a **parallel track that feeds the existing 54-stage Sales Funnel at Stage 06 (Lead Extraction)**, not a replacement for it.

**Audience:** AI Agents, employees, freelancers, virtual assistants, managers, developers, automation engineers, sales/marketing/customer success teams, CRM/ERP systems.

**Status:** Planning stage. Structural skeleton (this README + IMPLEMENTATION-PLAN.md) complete. No stage has been built to full pilot depth yet — see IMPLEMENTATION-PLAN.md §5 for the recommended pilot and batching order.

**Relationship to the Sales Funnel:** Every stage below produces content, traffic, or leads. Nothing in Track M closes a deal — every lead this track generates still lands in **Sales Funnel Stage 06 (Lead Extraction)** as an inbound record via the M22 bridge, then flows through the same 54 sales stages as an outbound lead would.

## Folder Standard

Every stage folder contains the **same 9 files as the Sales Funnel standard**, so both knowledge bases are navigable the same way by humans, VAs, and AI agents:

`README.md`, `methods.md`, `tools.md`, `automation.md`, `checklists.md`, `templates.md`, `resources.md`, `faq.md`, `references.md`.

Additional files are added only when a topic outgrows one file (the Sales Funnel did this for its Stage 06 pilot — Track M will do the same if a stage like M10 or M18 needs it).

## Why 22 Stages Instead of the Original 6 (M1–M6)

An earlier gap analysis proposed 6 broad tracks (Brand, SEO, Content, Social, Growth Hacking, Community). Those 6 are kept here as **Phases A–H** (grouping labels), but each is broken into single-topic stages — the same granularity the Sales Funnel uses (e.g., its Stage 16 "Email Outreach" is separate from Stage 17 "LinkedIn Outreach" rather than one combined "Outreach" stage). This keeps each stage's `tools.md`/`automation.md`/`checklists.md` focused enough to actually build to pilot depth, and keeps cross-referencing precise (e.g., M11 LinkedIn can link directly to M10's repurposing output instead of a vague "Social" reference).
