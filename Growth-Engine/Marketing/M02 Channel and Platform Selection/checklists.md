# M02 — Checklists

## Channel Selection Checklist

- [ ] Full channel universe reviewed at least once (organic, social, paid, partnership, referral, community, marketplace, PR, influencer, product-led — see `resources.md` for the full category list)
- [ ] Each candidate channel checked against the Sales Funnel Stage 02 ICP — is the ICP actually known to be present there?
- [ ] Capacity check done — can current team bandwidth actually sustain a real cadence on every channel being considered?
- [ ] Shortlist finalized and each channel assigned a primary tool and a monthly target (mirroring the existing SD-05 Inbound Channels table format)
- [ ] Non-selected channels documented with a stated reason (ICP mismatch, capacity, wrong stage) — not silently dropped

## Consistency Checklist (before handing off to downstream stages)

- [ ] M08 Editorial Calendar only scheduling across channels actually on the selected shortlist, not aspirational ones
- [ ] Each selected channel has a corresponding M11–M17 stage marked as "in scope" so that stage's own build-out isn't skipped or, conversely, isn't wasted effort on a channel that was never actually selected
- [ ] Channel shortlist table (Notion/Airtable) reflects the current, real decision — not left over from an earlier draft

## Periodic Review

- [ ] Shortlist re-reviewed if the ICP/persona (Sales Funnel Stages 02–03) changes
- [ ] Shortlist re-reviewed once M21 (Marketing Analytics) is live and real channel performance data exists — Method 1's ICP-fit reasoning should eventually be checked against actual results, not just assumed fit
- [ ] Non-selected list re-scanned periodically (Method 3 in `methods.md`) in case a previously-skipped channel is now worth reconsidering
