# M02 — FAQ

**Q: Is the channel shortlist in this stage final?**
It reflects the channels already named as active/in-setup in the existing SD-05 Inbound Marketing Hub doc at time of writing. It should be treated as the current best answer, not a permanent decision — re-review per the periodic-review checklist in `checklists.md` whenever the ICP changes or M21 (Marketing Analytics) produces real performance data.

**Q: Why isn't paid advertising on the shortlist?**
Per the existing Core Strategy & Positioning material, Nivy Digital's positioning explicitly emphasizes a multi-channel growth system "without relying only on ads" — that's a stated strategic choice, not an oversight. If that positioning changes, this stage's shortlist should be revisited.

**Q: Why doesn't this stage have a big automation workflow?**
Same reason as M01 — this is a judgment-call stage, not a production pipeline. The one real automation (keeping downstream stages notified when the shortlist changes) is covered in `automation.md`; nothing here fabricates a bigger workflow than actually exists.

**Q: What's the difference between this stage and M08 (Editorial Calendar)?**
M02 decides *which channels exist at all* for Nivy Digital to run content/outreach on. M08 decides *when* content goes out across those already-selected channels. M08 has no authority to add a new channel on its own — it schedules within what M02 has approved.

**Q: How does a channel move from "considered" to "selected"?**
Run it through the fit scorecard in `templates.md` Template 2 — ICP presence, capacity availability, and a clear decision. If selected, it gets added to the shortlist table and a corresponding M11–M17 (or other) stage build gets scheduled. If not selected, it goes into the non-selection log with a reason, per Method 4 in `methods.md`.

**Q: Do we need real analytics data before picking channels?**
Not for the first pass — Method 1 (ICP-backward selection) is a reasonable starting method without performance data. Real data from M21 should be used to *validate or challenge* the initial choices once it exists, not held up as a blocker to making any channel decision at all.
