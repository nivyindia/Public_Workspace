# M02 — Channel and Platform Selection

**Phase:** A — Foundation
**Status:** ✅ Built to pilot depth (2026-07-23)
**Feeds into:** M11–M17 (Social Channel Engines) — this stage decides *which* platforms get built out; M11–M17 decide *how* each chosen platform runs. M08 (Editorial Calendar) also reads this stage's output to know which channels to schedule for.
**Upstream input from:** M01 (Brand & Positioning Foundation) — channel choice should serve the positioning and reach the ICP/persona already defined, not be picked independently of them.

---

## 1. What This Stage Covers

M02 is a decision-layer stage, mostly 🔴 (strategic/judgment call) rather than 🟢 (automatable): given the full universe of possible acquisition channels, which ones does Nivy Digital actually commit resources to right now? This stage does not build out any channel (that's M11–M17's job) — it decides the short list and states why the rest are deliberately out of scope for now.

## 2. Sub-Stages

1. **Channel universe mapping** — the full landscape of acquisition channels available (organic, paid, partnership, referral, community, marketplace, etc.)
2. **Channel-to-ICP fit scoring** — for each candidate channel, does the Sales Funnel Stage 02 ICP actually spend time there?
3. **Channel-to-capacity fit** — does the current team (VAs, freelancers) have the bandwidth to run this channel to a real standard, or would adding it dilute the channels already committed to?
4. **Prioritized shortlist** — the actual channels selected for build-out this cycle, ranked
5. **Explicit non-selection list** — channels deliberately not being pursued yet, and why (mirrors the Negative-ICP pattern already used in Sales Funnel Stage 02)
6. **Monthly target-setting** — a light target per selected channel, to be refined once M21 (Marketing Analytics) is live

## 3. Why This Was Built the Way It Was

Per `IMPLEMENTATION-PLAN.md` §4 (Batch 1), this stage was built by mining two existing internal docs: a general "Customer Acquisition Channels" reference list (a broad, category-by-category map of channels relevant to agencies, freelancers, and digital marketing services — not Nivy-specific, used here as the universe to select *from*, not a list of channels already committed to) and the Inbound Channels table already living inside the "SD-05 — Inbound Marketing Hub" doc, which does name Nivy-specific channels, tools, and monthly targets (Blog/SEO, LinkedIn Inbound, Email Newsletter, Lead Magnets, YouTube). The SD-05 table is treated as the more authoritative, Nivy-specific source; the general list is treated as reference material for channels not yet evaluated.

## 4. Cross-References

- **M01** — Brand & Positioning Foundation (upstream: positioning and ICP alignment inform which channels make sense)
- **Sales Funnel Stage 02** — ICP Definition (upstream: channel choice should be justified against ICP, per sub-stage 2 channel mapping table already in that stage)
- **M03** — Content Pillars & Messaging Framework (parallel: pillars get applied differently per selected channel)
- **M08** — Editorial Calendar & Content Planning (downstream: schedules only across the channels selected here)
- **M11–M17** — Social Channel Engines (downstream: each stage assumes its platform was already selected here, not decided independently)

## 5. What's Not Built Yet

This stage names the channels currently prioritized per the existing SD-05 doc and lists the broader channel universe as reference. It does not include actual historical performance data comparing channels (that requires M21 Marketing Analytics to be running first) — channel choice here is scored on ICP-fit and capacity, not yet on real ROI data, and should be revisited once M21 produces that data.
