# 🔍 Monthly Audit Checklist

Run this every month. It certifies the system is still working as designed.

---

## Section 1 — Documentation Check

- [ ]  All SOPs accessible and links working
- [ ]  All Knowledge Base pages accessible
- [ ]  All role portals (VA, Supervisor, Manager) accessible
- [ ]  VA Trainee Path is current
- [ ]  Package Intelligence Hub tiers are up to date

---

## Section 2 — Performance Check

- [ ]  VA scorecards completed for all active VAs
- [ ]  All VAs have a current stage in Trainee Path
- [ ]  Supervisor QC log has entries for every week this month
- [ ]  No open flags older than 14 days

---

## Section 3 — Process Check

- [ ]  Onboarding Gate records complete for any new VAs this month
- [ ]  Deputy Protocol is named and current
- [ ]  Salary & Incentive Structure is current
- [ ]  Any disputes logged in Dispute & Grievance Process

---

## Section 4 — Navigation Check

- [ ]  New Joiner can navigate to first task in under 5 clicks
- [ ]  VA Dashboard links all working
- [ ]  Supervisor Dashboard links all working
- [ ]  Manager Dashboard links all working
- [ ]  System Navigation Map is current

---

## Section 5 — Autonomy Stack Check

- [ ]  Layer 1: Knowledge Base (6 KBs accessible)
- [ ]  Layer 2: SOPs (all 16 SOPs accessible)
- [ ]  Layer 3: Daily tasks checklists live
- [ ]  Layer 4: All roles have dashboards
- [ ]  Layer 5: QC system active
- [ ]  Layer 6: Scorecards live
- [ ]  Layer 7: Comms SOPs accessible
- [ ]  Layer 8: Automation docs accessible
