## ⏰ MORNING (Start of Shift — First 15 Minutes)

**Step 1 — Check CRM**

- [ ]  Open CRM sheet
- [ ]  Check for any leads due a follow-up today (filter by Follow-Up Stage + First Contact Date)
- [ ]  Confirm yesterday’s entries are all complete (no blank required fields)
- [ ]  Note today’s active lead count

**Step 2 — Check Messages**

- [ ]  Check LinkedIn for any replies or connection acceptances overnight
- [ ]  Check WhatsApp for any lead replies
- [ ]  Check Email inbox for any lead replies
- [ ]  Check Instagram DMs if that’s an assigned channel
- [ ]  For any positive reply → update CRM to Interested immediately, notify Supervisor

**Step 3 — Set Your Daily Target**

- [ ]  Confirm today’s lead target (from Supervisor brief or your assigned target)
- [ ]  Confirm today’s message target
- [ ]  Note any specific tasks assigned by Supervisor

---

## 📊 DAYTIME (Core Working Hours)

**Lead Sourcing Block (if assigned today)**

- [ ]  Run lead search on assigned platform (LinkedIn / Google Maps / Apollo)
- [ ]  Qualify each lead using the 5-point scoring check (KB-001 + SOP-VA-004)
- [ ]  Enter all qualified leads into CRM same day (SOP-VA-011)
- [ ]  Complete QC-001 before submitting lead batch

**Outreach Block**

- [ ]  Send new outreach messages (check daily volume limits in the relevant SOP)
- [ ]  Personalise every opener — no copy-paste without editing
- [ ]  Update CRM after every message sent (within 1 hour)
- [ ]  Complete QC-002 before sending any batch

**Follow-Up Block**

- [ ]  Check CRM for all leads on Day 3, Day 7, Day 14, or Day 30 today
- [ ]  Send correct follow-up template for each (SOP-VA-009)
- [ ]  Update CRM after every follow-up
- [ ]  Complete QC-003 for your follow-up batch

**Reply Handling (Ongoing Throughout Day)**

- [ ]  Any positive reply → CRM to Interested within 30 minutes, Supervisor notified
- [ ]  Any not-interested reply → Professional close, CRM to Dead
- [ ]  Any booked call → CRM to Booked, complete Call Handover Form (SOP-VA-014), submit 2+ hours before call

---

## 📝 END OF DAY (5:00–6:30 PM)

**Step 1 — Final CRM check**

- [ ]  All outreach and follow-up actions logged in CRM
- [ ]  All statuses accurate and up to date
- [ ]  No leads left in an inconsistent state (e.g., replied but still showing Contacted)

**Step 2 — Daily Report**

- [ ]  Open daily report template (SOP-VA-015)
- [ ]  Pull all numbers from CRM — do not estimate from memory
- [ ]  Calculate reply rate: Replies ÷ Messages Sent × 100
- [ ]  Calculate booking rate (if applicable)
- [ ]  Complete Blockers field (write "None" if none)
- [ ]  Complete Tomorrow’s Plan (3 fields)
- [ ]  Complete QC-004 (Report Quality Checklist)
- [ ]  Submit report by **7:00 PM in your team WhatsApp group**
