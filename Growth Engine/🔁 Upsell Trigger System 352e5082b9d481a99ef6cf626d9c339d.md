# 🔁 UPSELL TRIGGER SYSTEM

> **Core Rule:** Never pitch an upsell before the trigger moment. A client who hasn't seen results yet will reject any upsell. A client who has seen results will often say yes without much prompting.
> 

---

## 📘 HOW TO USE THIS SYSTEM

1. Find the client's current package in the table below
2. Check the trigger conditions — are any of them true?
3. If yes, use the conversation script in the right column
4. Log the upsell attempt in the client delivery tracker
5. If client says yes → hand off to Closer immediately

## 📝 HOW TO LOG AN UPSELL ATTEMPT

In the client delivery tracker, after any upsell conversation, log:

| Field | What to Write |
| --- | --- |
| Date | Today's date |
| Client Name | Client name |
| Current Package | What they have now |
| Upsell Pitched | What you suggested |
| Trigger Used | Which trigger from this table |
| Response | Interested / Not Now / No / Closed |
| Next Step | Follow-up date if not closed / Hand off to Closer if interested |

---

> ⚠️ **Rule:** If a client expresses interest in an upsell, do NOT try to close it yourself. Hand off to the Closer immediately. Your job is to identify the trigger and open the conversation — not close it.
