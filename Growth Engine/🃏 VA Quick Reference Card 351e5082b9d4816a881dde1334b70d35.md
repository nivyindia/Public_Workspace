## 📊 CRM Status Values (Use Exactly These)

| Status | When to Use |
| --- | --- |
| New | Just added, no contact yet |
| Contacted | First message sent |
| Following Up | In follow-up sequence |
| Interested | Replied positively |
| Booked | Call confirmed with date/time |
| Called | Discovery call completed |
| Closed Won | Became a client |
| Closed Lost | Did not convert |
| Dead | Full sequence done with no reply, or asked not to be contacted |
