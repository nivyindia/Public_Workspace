## 📅 4-WEEK MONTHLY DELIVERY CYCLE

### WEEK 1 — AUDIT & FOUNDATION

**Day 1–2: Access & Baseline Audit**

- Collect: Website access (CMS login or editor access), Google Search Console access, Google Analytics (or GA4) access
- Run technical SEO audit using Screaming Frog (free up to 500 URLs) or Ahrefs/SEMrush (if available)
- Document baseline: current ranking keywords (top 20), Domain Authority (DA), organic traffic (last 30 days)
- Save baseline report in client delivery folder — this is Month 0 benchmark

**Day 3: Keyword Research (Month 1 focus)**

- Identify 10–15 target keywords:
    - L1: 10 keywords (long-tail, low competition, local if applicable)
    - L2: 15 keywords (mix of long-tail + mid-competition head terms)
- Categorise keywords: Informational / Transactional / Navigational
- Map each keyword to an existing page or flag for new content creation
- Submit keyword list to client for approval before implementation

**Day 4–5: On-Page Audit (Existing Pages)**

- Audit top 10 existing pages for:
    - Missing or duplicate title tags
    - Missing or duplicate meta descriptions
    - H1/H2 structure issues
    - Missing alt text on images
    - Internal linking gaps
    - Page speed (use Google PageSpeed Insights)
- Document all issues in SEO audit sheet with priority labels (Critical / High / Medium)

---

### WEEK 2 — ON-PAGE IMPLEMENTATION

**Day 8–10: On-Page Fixes**

- Fix all Critical on-page issues identified in Week 1 audit
- Update title tags and meta descriptions for top 10 pages (primary + secondary keyword)
- Add/fix H1 — one H1 per page, contains primary keyword
- Add H2s that include secondary keywords naturally
- Fix broken internal links
- Compress oversized images + add alt text
- Submit all changes to supervisor for QC before publishing

**Day 11–12: Content Optimisation**

- Identify the 3 highest-traffic existing pages
- Optimise each page:
    - Add keyword naturally into first paragraph
    - Add 1 internal link to a relevant page
    - Add 1 external link to a high-authority source (not competitor)
    - Ensure minimum 800 words on transactional pages
- L2: Identify 1 content gap (keyword with no existing page) — brief new article for next cycle

**Day 12: Week 2 Internal Update**

- Log all changes in SEO implementation tracker
- Send client update: "Week 2 complete. X on-page fixes implemented. Expected ranking movement in 3–4 weeks."

---

### WEEK 3 — CONTENT & LINK BUILDING

**Day 15–17: Content Production (L2 only)**

- Write or brief 1 SEO article (minimum 1,000 words) targeting a gap keyword
- Article structure: H1 (primary keyword) → Introduction (150 words) → 3–5 H2 sections → FAQ section (3 questions) → CTA
- Include: primary keyword in first 100 words, 2–3 internal links, 1 external authority link
- Submit to supervisor for QC before publishing
- Publish and submit URL to Google Search Console for indexing

**Day 15–19: Link Building (Both Tiers)**

- L1: 5 citations (NAP consistency) — submit business to Google Business Profile, Yelp, Justdial, IndiaMART, Sulekha
- L2: 5 citations + 3 guest post outreach emails (identify relevant blogs in client niche)
- Log all submissions in link building tracker: site name, DA, date submitted, status

**Day 18: Week 3 Client Update**

- Share any new content published + link building progress summary

---

### WEEK 4 — REPORTING & NEXT MONTH PLANNING

**Day 22–24: Ranking Check & Analysis**

- Pull current rankings for all 10–15 target keywords
- Compare to Month 0 baseline: keywords moved up / down / entered top 10 / entered top 100
- Pull organic traffic data from GA4: sessions, users, bounce rate, top landing pages
- Check Google Search Console: impressions, clicks, CTR, average position changes

**Day 25–27: Monthly Report Compilation**

- Build monthly SEO report:
    - Summary: Month X of Y. What we worked on. What moved.
    - Keyword Rankings Table: Keyword | Month 0 position | This Month | Change
    - Traffic Table: Organic Sessions | Organic Users | Top 3 pages
    - On-Page Work Done (list of pages optimised)
    - Content Published (list with URLs)
    - Links Built (count by type)
    - Next Month Plan: 3 specific priorities
- Submit to supervisor for QC

**Day 28–30: Client Delivery**

- Send monthly report
- Include a short note: "SEO is a compounding channel. Months 3–6 show the steepest growth."
- Log delivery date in tracker

## ✅ QC CHECKLIST — BEFORE PUBLISHING ANY CHANGE

- [ ]  Title tag: contains primary keyword, 50–60 characters
- [ ]  Meta description: contains primary keyword, 150–160 characters, includes CTA
- [ ]  H1: one per page, contains primary keyword
- [ ]  No duplicate title tags or meta descriptions across the site
- [ ]  All new URLs are lowercase, hyphenated, no special characters
- [ ]  All images have alt text (descriptive, keyword-relevant where natural)
- [ ]  Internal links: at least 1 per new page pointing to an existing page
- [ ]  No broken links on edited pages (use Broken Link Checker)
- [ ]  New content submitted to Google Search Console for indexing
- [ ]  Changes logged in SEO implementation tracker before publishing

## 🚨 ESCALATION RULES

| Situation | Action | Escalate To |
| --- | --- | --- |
| Traffic drops > 30% in one month | Immediately check for Google algorithm update (check Search Engine Roundtable). Check for manual penalty in GSC. Do not wait for month-end. | Supervisor same day |
| Google manual penalty notice in GSC | Do not attempt disavow without supervisor sign-off. Screenshot penalty notice. | Supervisor immediately |
| Client requests keyword that violates Google guidelines (e.g. misleading health claims) | Do not implement. Explain policy risk to client. Propose alternative. | Log + Supervisor |
| Website goes down or CMS access lost | Notify client + supervisor immediately. Pause all publishing actions. | Client + Supervisor |
| Client changes entire website structure | Pause all SEO work. Full re-audit required. Notify supervisor. | Supervisor immediately |
| No ranking movement for 90+ days | Conduct full audit: technical issues, algorithm updates, competitor growth. Present findings report. | Supervisor |
