# 📝 7. PROMPT TEMPLATES LIBRARY {#prompts}

## Blog Post Prompt

```
Write a 1,500-word blog post titled "[TITLE]" for Nivy Digital, 
a VA and digital marketing agency based in India serving US/UK/AU/UAE clients.
Tone: professional, approachable, clear, action-oriented. No jargon.
Include: intro hook, 5-6 H2 sections, real examples, conclusion with CTA.
Target keyword: [KEYWORD] — include 4-6 times naturally.
End with: "Book your free 30-min strategy call at [link]"
```

## LinkedIn Post Prompt

```
Turn this blog post excerpt into a LinkedIn post:
[paste excerpt]

Requirements:
- Start with a hook line that stops the scroll
- 200-300 words max
- Use short paragraphs (1-2 sentences each)
- End with a question to drive comments
- Don't use hashtags more than 3
- Tone: confident, human, founder voice
```

## Cold Email Prompt

```
Write a cold email outreach sequence (5 emails) for Nivy Digital targeting 
[NICHE] founders in [COUNTRY].
Service: [VA / Marketing / Automation]
Key pain point: [PAIN]
Key result we deliver: [RESULT]
CTA: Book a 30-min call at [Cal.com link]
Tone: direct, respectful, not pushy. Subject lines should be curiosity-driven.
```

## Proposal Prompt

```
Write a business proposal for Nivy Digital for client [NAME] at [COMPANY].
Their situation: [describe from discovery call notes]
Recommended package: [package name and price]
Key outcomes they care about: [list outcomes]
Include: executive summary, solution overview, investment section, ROI calculation, next steps.
Tone: confident, results-focused, human.
```

## SOP Writing Prompt

```
Write a detailed step-by-step SOP for [TASK].
This will be followed by a VA with intermediate experience.
Include: purpose, tools needed, step-by-step instructions, quality checklist, common mistakes to avoid.
Format: numbered steps, clear language, no ambiguity.
```
