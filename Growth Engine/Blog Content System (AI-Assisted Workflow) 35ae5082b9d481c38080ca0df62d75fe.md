# ⚙️ System Overview {#overview}

**Target:** 8 blog posts per month (2 per week)

**Time per post:** 90 minutes total (30 min AI + 30 min edit + 30 min SEO + publish)

**Tools needed:** Claude AI / ChatGPT, Ahrefs/Google, WordPress/Webflow, Canva (for featured image)

**Blog categories on the website:**

- Accounting & Tax Tips
- Digital Marketing for SMEs
- Tech & Automation
- International Business
- Nivy Digital Updates / Case Studies

---

# 🔍 Step 1: Keyword Research {#keywords}

1. Go to **Ahrefs Free Keyword Generator** (or Semrush)
2. Enter a broad topic (e.g., "GST filing", "UK bookkeeping", "LinkedIn lead generation")
3. Filter: volume > 100, keyword difficulty < 30 (for new sites, target < 20)
4. Select keyword — confirm search intent (is it informational? Perfect for blog.)
5. Note the keyword, volume, and top-ranking competitor URL
6. Add to content calendar

---

# 🤖 Step 2: AI-Assisted Drafting {#drafting}

**Prompt template for Claude:**

```
Write a 2,000-word blog post targeting the keyword: "[KEYWORD]"

Target audience: [SME founders / UK accountants / Indian startup owners — choose one]
Tone: Professional but conversational. Helpful, not salesy.

Structure:
- H1: Include the keyword
- Introduction (150 words): Hook, context, what they’ll learn
- H2 Section 1: [Key subtopic]
- H2 Section 2: [Key subtopic]
- H2 Section 3: [Key subtopic]
- H2 Section 4: [Key subtopic]
- FAQ section: 5 questions a reader would Google about this topic
- Conclusion with CTA: "Book a free consultation with Nivy Digital"

Do not include fluff. Every sentence must add value. Include specific examples, numbers, and actionable steps.
```

---

# ✏️ Step 3: Human Edit & Brand Voice {#edit}

**Editing checklist:**

- [ ]  Read the full draft aloud — does it sound natural?
- [ ]  Remove any AI clichés ("In today’s fast-paced world...", "It’s worth noting that...")
- [ ]  Check all facts, numbers, and claims — verify before publishing
- [ ]  Add 1–2 personal examples or Nivy-specific context
- [ ]  Ensure CTA is specific: "Book a free 30-min call" + [Cal.com](http://Cal.com) link
- [ ]  Run through Grammarly for typos

---

# 🔍 Step 4: On-Page SEO Optimisation {#seo}

- [ ]  H1 contains exact target keyword
- [ ]  Keyword in first paragraph (naturally)
- [ ]  Keyword in at least 2 H2 subheadings
- [ ]  Meta title: keyword + brand name, under 60 characters
- [ ]  Meta description: keyword + benefit, under 160 characters
- [ ]  URL slug: short, keyword-only (e.g., /gst-filing-guide-india)
- [ ]  Alt text on featured image contains keyword
- [ ]  2–3 internal links to other blog posts or service pages
- [ ]  1–2 external links to authoritative sources
- [ ]  Word count: 1,500+ (2,000–2,500 preferred)

---

# 🚀 Step 5: Publish & Repurpose {#publish}

1. Upload to WordPress/Webflow — format with H1, H2s, bold text, bullet points
2. Upload featured image (Canva: 1200x628px, branded)
3. Set category and tags
4. Publish or schedule
5. Submit URL to Google Search Console → Inspect URL → Request Indexing
6. Repurpose (see Content Calendar system):
    - LinkedIn post — key takeaway from the post
    - Instagram carousel — 5 tips from the post
    - Newsletter section — summary + link
