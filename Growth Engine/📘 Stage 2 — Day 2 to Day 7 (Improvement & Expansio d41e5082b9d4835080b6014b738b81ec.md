## 📝 REAL SCRIPTS — MULTI-CHANNEL OUTREACH (Day 5)

> Use these word-for-word. Personalise [NAME] and [NICHE] only.
> 

### 🔵 LinkedIn Connection Request

```
Hi [NAME], I work with [NICHE] businesses helping them get more qualified leads. Would love to connect.
```

### 🔵 LinkedIn First Message (After Connect)

```
Hi [NAME], thanks for connecting.

I help [niche e.g. roofing / coaching / agency] businesses book more calls using outreach.

Are you currently looking to grow your client base?
```

### 🟢 WhatsApp First Message

```
Hi [NAME], I found your profile online — I work with [NICHE] businesses to help them get more leads and booked calls.

Would it be okay to ask you one quick question?
```

### 📧 Email Subject: Quick question for [NAME]

```
Hi [NAME],

I help [niche] businesses get more inbound leads without spending more on ads.

Would a quick 15-minute call this week make sense?

[Your Name]
```

### 📸 Instagram / Facebook DM

```
Hey [NAME]! Love what you're building with [Business/Page Name].

I help businesses like yours get more clients through outreach — would you be open to a quick chat?
```

> ⚠️ Rule: Always send one message at a time. Do not send 3 platforms at once to the same lead.

## 📝 REAL SCRIPTS — FOLLOW-UP SEQUENCE (Day 6)

> Use these as follow-ups when lead has NOT replied. Space them 1–2 days apart.
> 

### Follow-Up 1 (Day after first message)

```
Hi [NAME], just following up on my message from yesterday.

Is this something that's relevant for your business right now?
```

### Follow-Up 2

```
Hey [NAME], I know you're busy — just wanted to bump this up.

We've helped [similar businesses] book 3–5 extra calls per week. Would that be useful?
```

### Follow-Up 3 (Final)

```
Hi [NAME], last follow-up from me — I don't want to keep bothering you.

If timing isn't right, no worries at all. Feel free to reach out whenever.
```

### ✅ Reply Handling — When They Say "Tell Me More"

```
Great! We help [NICHE] businesses get more qualified leads and booked calls through outreach.

It works best when we understand your setup first — can we jump on a 15-minute call this week?
```
