| --- | --- |

| Acceptance rate target | 25–35% |
| Reply rate target (after connecting) | 15–25% |
| Calls booked per week (from LinkedIn) | 3–5 |
| Sequence length | 3 messages (connect → intro → value → CTA) |

# ⚠️ Daily Limits & Safety Rules {#limits}

> LinkedIn monitors for automated or high-volume activity. Stay within safe limits to protect the account.
> 

| Action | Safe Daily Limit |
| --- | --- |
| Connection requests | Max 20–25/day |
| Messages to 1st connections | Max 50/day |
| Profile views | Max 100/day |
| InMail (paid) | Per plan limits |

**Rules:**

- Never use automation bots (Dux-Soup, Expandi, etc.) without VPN + warm-up
- Always personalise at least the first line of every message
- Space out connection requests throughout the day (not all at once)
- If account gets restricted — stop immediately, wait 7 days

# 💬 Connection Request Templates {#connection}

## Template A — Founder / Solopreneur

```
Hi [First Name],

Noticed you're building [Company] — love what you're doing in [industry/niche].

I work with founders who need reliable digital ops support (lead gen, outreach, content) so they can focus on growing.

Would love to connect!

— [Your Name]
```

## Template B — Coach / Consultant

```
Hi [First Name],

I help coaches and consultants build consistent outreach and content systems — without spending hours doing it themselves.

Looks like you're doing great work with [their niche] — connecting to follow your journey.

— [Your Name]
```

## Template C — SME / Director

```
Hi [First Name],

I help growing businesses build marketing and lead gen operations — without the overhead of a full in-house team.

Connecting because [Company] looks like the kind of business we love working with.

— [Your Name]
```

**Rules for connection requests:**

- Max 300 characters (LinkedIn note limit)
- Always use first name
- One specific personalised detail minimum
- No pitch in the connection request

# 🔄 Follow-Up Message Sequences {#followup}

## Sequence Overview

```
Day 0:  Connection request sent (personalised note)
Day 1:  Connection accepted → send Message 1 (Intro)
Day 4:  No reply → send Message 2 (Value)
Day 8:  No reply → send Message 3 (Soft CTA)
Day 14: No reply → Mark as "No Response" in CRM
```

## Message 1 — Intro (Send on connect)

```
Hi [First Name], thanks for connecting!

I wanted to introduce what we do at Nivy Digital — we help founders and SMEs run their lead generation, outreach, and digital operations using trained VAs powered by AI.

No pitch — just wanted to say hi and let you know we're here if you ever need an extra pair of hands.

[Your Name]
```

## Message 2 — Value (Day 4)

```
Hey [First Name],

Sharing something useful — [relevant insight, tip, or stat about their industry/pain point].

We've been helping founders like yourself [specific outcome, e.g., "build a 500-lead/week pipeline without lifting a finger"].

Happy to share how if useful. No pressure at all.

[Your Name]
```

## Message 3 — Soft CTA (Day 8)

```
Hi [First Name],

Last message — I promise 😄

If offloading your outreach, admin, or lead gen is on your mind, I'd love to offer a free 20-min strategy call — no commitment.

[Calendly link]

Either way, best of luck with [Company]!

[Your Name]
```

# 📅 Booking the Discovery Call {#booking}

1. When a prospect replies positively — send Calendly link immediately
2. Calendly page: **"Nivy Digital — Free 20-Min Strategy Call"**
3. Pre-call: VA sends confirmation + context form
4. On call: Founder or senior VA leads — use Sales Funnel SOP (SD-07)
5. Post-call: Enter outcome in HubSpot within 1 hour

# 📊 Tracking & Reporting {#tracking}

| Field to Track | Where |
| --- | --- |
| Connection sent | HubSpot contact — Activity log |
| Connection accepted | Update contact status |
| Messages sent (1, 2, 3) | HubSpot activity + date |
| Reply received | Flag as Hot, update to Replied stage |
| Call booked | Update deal stage: Discovery Scheduled |
| Call outcome | Update to: Proposal Sent / Not Qualified / Nurture |

**Weekly report (VA sends every Monday):**

- Connections sent
- Acceptance rate
- Replies received
- Calls booked
- Pipeline value added
