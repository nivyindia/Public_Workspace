- Archive resolved items monthly

## How to Identify a System Issue vs a Person Issue

- Same issue reported by 2+ different people → System issue. Fix the system.
- Issue only from one person → Coaching or training. Address the person.
- Issue keeps coming back after fix → Root cause not addressed. Dig deeper.
