# 🔲 Pre-Build Checklist {#pre-build}

- [ ]  Domain purchased and DNS access confirmed (Namecheap/GoDaddy/Cloudflare)
- [ ]  Hosting selected (Hostinger/Kinsta/Cloudflare Pages for static)
- [ ]  Platform decided: WordPress / Webflow / Framer / Custom
- [ ]  Brand assets ready: logo (SVG + PNG), colour palette (hex codes), fonts
- [ ]  Sitemap mapped out (list of all pages)
- [ ]  Content written or assigned for each page
- [ ]  Competitor sites reviewed for design reference
- [ ]  Google Analytics 4 account created
- [ ]  Google Search Console account created
- [ ]  Business email set up (e.g. [hello@nivydigital.com](mailto:hello@nivydigital.com))

# 🎨 Design & Content {#design}

## Pages to Build (Minimum)

| Page | Purpose | Priority |
| --- | --- | --- |
| Home | First impression, convert visitors | 🔴 Critical |
| About | Build trust, tell the story | 🔴 Critical |
| Services | Detail all offerings | 🔴 Critical |
| Contact | Drive enquiries | 🔴 Critical |
| Blog | SEO + authority | 🟠 High |
| Case Studies | Social proof | 🟠 High |
| Pricing (optional) | Qualify leads | 🟡 Medium |
| Book a Call | Direct conversion | 🔴 Critical |

## Content Rules

- Every page has a single H1 tag
- Primary keyword in H1, first paragraph, and meta description
- CTA on every page ("Book a Free Call", "Get a Quote")
- Images compressed to under 200KB each (use TinyPNG)
- Alt text on every image

# ⚙️ Technical Setup {#technical}

- [ ]  SSL certificate active (https://)
- [ ]  WWW redirect configured (non-www → www or vice versa, consistent)
- [ ]  XML sitemap created and submitted to Google Search Console
- [ ]  Robots.txt file configured
- [ ]  404 error page created (branded, with nav links)
- [ ]  Google Analytics 4 tracking code installed
- [ ]  HubSpot tracking code installed
- [ ]  Schema markup added (Organization + LocalBusiness)
- [ ]  Page speed tested (target: under 3 seconds on mobile)
- [ ]  Mobile responsiveness tested on iPhone + Android
- [ ]  Contact form tested (submission → email confirmation working)
- [ ]  [Cal.com](http://Cal.com) embed or booking widget installed on Book a Call page
- [ ]  Cookie consent banner installed (GDPR compliance)
- [ ]  Privacy Policy and Terms pages live

---

# 🚀 Launch Checklist {#launch}

- [ ]  All pages proofread (no typos, broken links, placeholder text)
- [ ]  All images are optimised
- [ ]  All forms tested end-to-end
- [ ]  Booking widget tested
- [ ]  Social meta tags (OG tags) set for link previews
- [ ]  Favicon uploaded
- [ ]  Google Business Profile created and linked
- [ ]  Social media profiles updated with website link
- [ ]  DNS fully propagated (test with [whatsmydns.net](http://whatsmydns.net))
- [ ]  Announce launch on LinkedIn + WhatsApp + social

---

# 🔧 Post-Launch Maintenance {#maintenance}

**Monthly Tasks:**

- Review Google Analytics: top pages, traffic sources, bounce rate
- Check Google Search Console: impressions, clicks, any errors
- Publish minimum 4 blog posts
- Update any outdated service information
- Check all forms still working

**Quarterly Tasks:**

- Full page speed audit
- Review and update all CTAs
- Add new case studies or testimonials
- Backlink audit (Ahrefs/Semrush)
