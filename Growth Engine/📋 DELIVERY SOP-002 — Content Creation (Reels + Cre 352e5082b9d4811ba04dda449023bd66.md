## 🎯 PURPOSE

This SOP governs the **end-to-end delivery** of the Content Creation package for every active client. It is a production system — not a one-off task. Every VA delivering content must batch-produce, not create day by day. Supervisors use this to QC output before client delivery.

## 🗓️ MONTHLY DELIVERY CYCLE

### WEEK 1 — PLANNING & SCRIPTING (Day 1–7)

**Day 1–2 — Client Brief (New Clients Only)**

- [ ]  Send Content Brief Form: collect niche, tone of voice, content pillars (3–5), reference reels they like, brand colours, logo, fonts, any topics to avoid
- [ ]  Confirm video source: does client provide raw footage, or does VA create graphics-only reels?
- [ ]  Confirm approval workflow: WhatsApp or Google Drive folder
- [ ]  Add client to Content Production Tracker

**Day 3–5 — Monthly Script Batch**

- [ ]  Write all reel scripts for the month in one sitting — do NOT script one by one
- [ ]  Script format for every reel:
    - **Hook** (0–3 sec): pattern interrupt — question, bold statement, or visual surprise
    - **Value** (3–25 sec): the actual content — tip, story, reveal, transformation
    - **CTA** (last 3 sec): follow, save, comment, DM, book
- [ ]  Script length: 15–30 sec = 60–90 words
- [ ]  L2 Growth: write custom scripts per client niche
- [ ]  L1 Starter: use approved script templates, swap niche-specific words
- [ ]  Submit all scripts to Supervisor for review before production begins

**Day 5–7 — Content Calendar**

- [ ]  Build monthly calendar: map each reel and creative to a publishing date
- [ ]  Minimum gap between posts: 1 day
- [ ]  Reels: publish Tue, Thu, Sat (highest reach days)
- [ ]  Creatives: publish Mon, Wed, Fri
- [ ]  Submit calendar to client for approval by Day 7

---

### WEEK 2 — PRODUCTION BATCH 1 (Day 8–14)

**Reel Editing (Batch 1: first 4 reels for Starter / first 8 for Growth)**

- [ ]  Collect all assets: footage (if client-provided), music, brand kit, script
- [ ]  Edit in CapCut or Adobe Premiere (as per client preference)
- [ ]  Every reel must have:
    - [ ]  Auto-captions ON (white text, black outline, 30–36pt)
    - [ ]  Hook text on screen in first 2 seconds
    - [ ]  Trending audio (check Instagram Reels trending audio weekly every Monday)
    - [ ]  Branded end card (logo + CTA)
    - [ ]  Exported at **1080×1920 (9:16), MP4, under 90 sec**
- [ ]  Do not use copyrighted music for client accounts — use royalty-free or trending Instagram audio only

**Graphic Creatives (Batch 1: first 6 creatives for Starter / first 10 for Growth)**

- [ ]  Create in Canva using client brand template
- [ ]  Every creative must have:
    - [ ]  Brand colours and font (no off-brand colours)
    - [ ]  Clear headline (max 8 words)
    - [ ]  Sub-text or supporting point (1–2 lines)
    - [ ]  Logo in corner
    - [ ]  CTA or engagement prompt
- [ ]  Sizes: 1080×1080 (feed), 1080×1920 (story/reel cover)

**Batch 1 Approval**

- [ ]  Bundle Batch 1 into a Google Drive folder: `/Client Name/Month/Batch 1/`
- [ ]  Label clearly: `Reel 1 — [Topic]`, `Creative 1 — [Topic]`
- [ ]  Send to client with caption drafts attached in a Google Doc
- [ ]  Chase at 24 hrs if no reply. Escalate to Supervisor at 48 hrs.

---

### WEEK 3 — PRODUCTION BATCH 2 (Day 15–21)

**Reel Editing (Batch 2: remaining reels)**

- [ ]  Same checklist as Batch 1
- [ ]  Incorporate any feedback from Batch 1 approval
- [ ]  Check: are reels varied? No two consecutive reels should use the same format

**Graphic Creatives (Batch 2: remaining creatives)**

- [ ]  Same checklist as Batch 1
- [ ]  Rotate creative types: carousel, quote card, infographic, product/service highlight

**Batch 2 Approval**

- [ ]  Same approval process as Batch 1
- [ ]  All content for the month must be approved by Day 21

---

### WEEK 4 — CAPTION WRITING, HASHTAGS & HANDOVER (Day 22–28)

**Caption Writing (all posts)**

- [ ]  Caption structure: **Hook line** (makes them stop) → **Value/Story** (2–4 lines) → **CTA** (clear ask)
- [ ]  Maximum caption length for feed posts: 150–220 words
- [ ]  Add 1 line gap between each section (improves readability on mobile)
- [ ]  No emojis in first line (affects algorithm reach)
- [ ]  End with a question or CTA: “Save this for later” / “Comment below” / “DM us [keyword]”

**Hashtag Research**

- [ ]  L1 Starter: use approved hashtag template set (20 hashtags per post, mix of small/medium/large)
- [ ]  L2 Growth: custom hashtag research per post topic (use Instagram search + Flick or free tools)
- [ ]  Never use banned hashtags (check monthly)
- [ ]  Mix: 5 niche hashtags + 5 medium (100K–1M) + 5 large (1M+) + 5 branded/community

**Final Handover to Supervisor**

- [ ]  All reels + creatives + captions + hashtags in one organised Google Drive folder
- [ ]  Supervisor QC checklist completed (see below)
- [ ]  Supervisor approves and delivers to client (or authorises VA to deliver)

**L2 Growth — Monthly Performance Review**

- [ ]  Pull from Instagram Insights: best reel (views, saves, shares), best creative (reach, engagement), follower growth
- [ ]  Fill Monthly Content Report Template: what worked, what to replicate, what to change
- [ ]  Submit to Supervisor by Day 28

## ✅ QUALITY CONTROL CHECKLIST (Supervisor Use)

Before approving any content batch for client delivery:

**Reels**

- [ ]  Hook appears in first 2 seconds
- [ ]  Auto-captions are ON and readable
- [ ]  Audio is trending (not copyrighted)
- [ ]  Branded end card with CTA present
- [ ]  Exported correctly: 1080×1920, MP4, under 90 sec
- [ ]  Script follows Hook → Value → CTA structure
- [ ]  No competitor brands, logos, or references visible

**Graphics**

- [ ]  Brand colours and fonts match client kit exactly
- [ ]  Headline under 8 words
- [ ]  Logo present and correctly placed
- [ ]  No spelling or grammar errors
- [ ]  CTA or engagement prompt present

**Captions**

- [ ]  Hook in first line (no generic opener like “Hey guys”)
- [ ]  CTA at end of every caption
- [ ]  No banned hashtags
- [ ]  Hashtag count: 15–25 per post

**Calendar & Process**

- [ ]  All content delivered to Supervisor by Day 22
- [ ]  Client approvals confirmed before scheduling
- [ ]  Monthly report submitted (L2 only) by Day 28

## 📱 TRENDING AUDIO PROCESS (Weekly, Every Monday)

This is a critical task that keeps reels performing. Must be done every Monday before production starts.

1. Open Instagram on a personal/test account
2. Go to Reels → tap any reel → tap the audio name at the bottom
3. Check: how many reels use this audio? If **500K–2M uses** = currently trending sweet spot
4. Save 5–10 trending audios to the **Weekly Audio Bank** (shared Google Sheet)
5. Match saved audio to client niche (upbeat for lifestyle/fitness, calm for finance/consulting, etc.)
6. Never reuse the same audio for the same client two months in a row
