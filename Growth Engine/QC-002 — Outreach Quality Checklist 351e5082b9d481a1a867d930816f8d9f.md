# QC-002 — Outreach Quality Checklist

> **Version:** 1.0 | **Last Updated:** April 29, 2026 | **Owner:** VA Manager | **Status:** Live
> 

> 🚨 Complete this checklist BEFORE sending any outreach message. One poor message reflects on Nivy's brand.
> 

---

## QC-002 — Outreach Quality Checklist

Complete for every outreach batch before sending.

### For Each Message:

- [ ]  Message is addressed to the correct person (right name, right lead)
- [ ]  Opener is personalised — references the lead's business, industry, role, or a post
- [ ]  Message is under 5 lines (first contact) or under 6 lines (follow-up)
- [ ]  No typos or grammatical errors (re-read before sending)
- [ ]  No Nivy pricing, package lists, or brochures attached
- [ ]  Message ends with a soft question, not a pitch
- [ ]  Correct platform used for this lead (LinkedIn DM / WhatsApp / Email / Instagram)
- [ ]  Daily volume limits not exceeded (check SOP for the relevant platform)

### After Sending:

- [ ]  CRM Last Contact Date updated to today
- [ ]  CRM Follow-Up Stage updated (FU0 for first contact)
- [ ]  Status updated to "Contacted" if this is the first message
- [ ]  Status updated to "Following Up" if this is a follow-up message

---

## Platform Spot-Check (5 minutes before sending)

For LinkedIn:

- [ ]  Connection request note is under 300 characters
- [ ]  Daily connection limit not exceeded (max 20–25)

For WhatsApp:

- [ ]  Lead's phone number has a country code
- [ ]  Time is between 8am–8pm in the lead's local timezone

For Email:

- [ ]  Correct Nivy outreach email address used (not personal Gmail)
- [ ]  No attachment in first email
- [ ]  Subject line is personalised

For Instagram:

- [ ]  No link in the first DM
- [ ]  Daily limit not exceeded (max 10–15)

---

**If a message fails any check — fix it before sending. One generic or error-filled message is worse than no message.**
