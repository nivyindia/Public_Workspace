# 🃏 Supervisor Quick Reference Card

Bookmark this. One page. Everything you need fast.

---

## The Supervisor Workflow

1. Morning: Check VA logs → QC 3 conversations → flag issues
2. Midday: Respond to VA escalations within 2 hours
3. End of day: Run EOD report → update team tracker → confirm all VAs submitted reports

---

## QC Standards (What to Look For)

- Message quality: Professional tone, no spelling errors, SOP-compliant
- Follow-up timing: Must be within 24h for warm leads, 3 days for cold
- Logging: Every lead, every message must be logged — no exceptions
- Report submission: EOD report due before sign-off — every day

---

## SLA Standards

| Task | Standard |
| --- | --- |
| Respond to lead reply | Within 2 hours |
| Follow-up on warm lead | Within 24 hours |
| Follow-up on cold lead | Within 3 days |
| Archive unresponsive lead | After 7 days no reply |
| EOD report submission | Before VA signs off |
| Escalation response | Within 2 hours |

---

## Escalation Quick Index

| Situation | Action |
| --- | --- |
| VA making SOP errors | Retrain → log it |
| VA missing targets | 1:1 check-in → coaching note |
| VA repeated issues | Escalate to Manager |
| System issue | Log in System Feedback Log |
| VA absent without notice | Activate Deputy Protocol |

---

## The 3 Supervisor Rules

1. Every flag gets logged — no verbal-only feedback
2. QC is daily, not weekly — 3 conversations minimum
3. If you're absent, Deputy Protocol activates — no gap in coverage
