# 🗓️ DAILY VA REPORTING SOP {#daily}

**Every VA sends a daily update at end of their shift via Slack or WhatsApp:**

```
📊 DAILY UPDATE — [Date]
VA: [Name] | Client: [Client Name] | Hours worked: [X]

✅ COMPLETED TODAY:
• [Task 1 — brief description + output]
• [Task 2]
• [Task 3]

🔄 IN PROGRESS:
• [Task that carries over tomorrow]

❌ BLOCKERS / QUESTIONS:
• [Anything blocking progress — or "None"]

⏱️ Hours used today: [X] | Total this week: [X] / [weekly target]
```

**Founder reviews daily updates every morning (5 min).**

If no update received by end of shift: Slack reminder sent.

# ✅ OUTPUT QUALITY STANDARDS {#quality}

## Universal Quality Rules

- All written output: zero typos, Grammarly checked before sending
- All deliverables: match the brief exactly (ask if unclear, don’t guess)
- Turnaround: tasks completed within agreed deadline (flag 24h before if at risk)
- Communication: respond to client messages within 2 hours during working hours
- Professionalism: all external-facing communication on behalf of Nivy is polite, clear, and branded

## Quality Check Process

1. VA self-reviews before submitting (Grammarly + brief re-read)
2. Account manager spot-checks 20% of all output weekly
3. Client feedback captured in monthly NPS survey
4. Issues flagged → documented in VA performance log

# 🗓️ MONTHLY PERFORMANCE REVIEW {#monthly-review}

**Done by Founder / Account Manager at end of each month.**

## Review Scorecard

| Category | Weight | Score (1–5) | Notes |
| --- | --- | --- | --- |
| Task completion rate | 30% | — | % of assigned tasks completed on time |
| Output quality | 30% | — | Based on spot-checks + client feedback |
| Communication | 20% | — | Responsiveness, clarity, professionalism |
| Initiative | 10% | — | Did they flag issues proactively? Improve on own? |
| Activity targets met | 10% | — | Outreach/content numbers vs target |

**Overall score = Weighted average**

- 4.5–5.0: Excellent — eligible for bonus / pay review
- 3.5–4.4: Good — continue, feedback given
- 2.5–3.4: Needs improvement — PIP (performance improvement plan)
- <2.5: Serious concern — reassignment or termination

## Monthly Review Meeting Agenda (15 min)

1. Review scorecard together (5 min)
2. Celebrate wins (2 min)
3. Address any concerns (3 min)
4. Set 3 goals for next month (5 min)

# 🚨 PERFORMANCE ISSUES & RESPONSE {#issues}

| Issue | First Response | If Continues |
| --- | --- | --- |
| Missed daily update | Slack reminder same day | Formal note in performance log |
| Task completed late (once) | Discuss reason, document | Formal warning after 3x |
| Quality issue (once) | Feedback + re-do task | Training + closer supervision |
| Client complained | Immediate founder review | Reassignment if needed |
| Consistent underperformance | PIP: 2-week improvement plan | Replace VA |
| No-show (no communication) | Immediate escalation | Termination |
