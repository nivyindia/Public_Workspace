## BANT Assessment Log Template
```
Opportunity: [name]
Budget: [confirmed / unclear / no budget]
Authority: [decision maker / influencer / unknown]
Need: [urgent / moderate / unclear]
Timeline: [stated timeframe]
Decision: [Qualified / Not-Yet-Qualified / Disqualified]
Reasoning: [1-2 sentences]
```

## Qualification Decision Rules (starting point — tune per segment)
- **Qualified:** Budget confirmed or plausible, speaking with a decision-maker or a credible path to one, a clear need, and a realistic timeline within the sales cycle window
- **Not-Yet-Qualified:** Missing 1-2 elements but shows genuine potential — route to nurture, revisit in a defined period
- **Disqualified:** No budget path, no realistic need, or timeline far outside a workable window
