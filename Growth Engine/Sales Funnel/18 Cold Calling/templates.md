# Templates — 18 Cold Calling

[⬅ Back to README](README.md)

## Opening Script (first 10-15 seconds)
```
Hi [First Name], this is [Your Name] from [Company] — did I catch you at a
completely bad time, or do you have 30 seconds?
```
(Pause for response — asking permission up front reduces immediate hang-ups.)

## Reason-for-Call + Discovery Question
```
The reason I'm calling — we work with [industry] businesses on [pain area],
and I was curious whether that's something on your radar at [Company Name]
right now, or not really a priority?
```

## If Interested → Booking
```
Great — the best next step would be a quick 15-20 minute call with our team
to see if there's a real fit. Do you have your calendar handy, or should I
send over a couple of time options?
```

## If Not Now → Soft Close
```
Totally understand. Would it be alright if I checked back in [3 months / other
sensible interval], or is there someone else on your team better placed for this?
```

## Voicemail Script
```
Hi [First Name], this is [Your Name] from [Company]. I was calling about
[pain area] for [Company Name] — I'll follow up with a quick email as well.
If it's useful sooner, feel free to call back at [number]. Thanks!
```

## Formatting Rules
- Ask permission before pitching — it materially reduces early hang-ups
- One discovery question before any pitch, not a monologue
- Voicemail under 20 seconds, always followed by an email same day
