# Checklists — 20 SMS Outreach

[⬅ Back to README](README.md)

## Pre-Send Compliance QC
- [ ] Lawful basis confirmed for this contact/message type before sending
- [ ] Opt-out language included where required by local regulation
- [ ] Message type matches an approved use case (confirmation/reminder/re-engagement) — not a cold open

## Per-Message QC
- [ ] Character count within limit (typically 160 chars for a single-segment SMS)
- [ ] Correct booking/meeting details populated (no stale placeholder data)
- [ ] Sender ID/number recognizable to the recipient

## Ongoing QC
- [ ] STOP/opt-out replies actioned immediately, not batched
- [ ] Delivery rate monitored — a drop usually indicates bad number data (feed back to Stage 10)
- [ ] No contact SMS'd cold without documented sign-off on lawful basis

## Duplicate / Accuracy / Completeness Checks
- [ ] No duplicate reminder sent for the same booking
- [ ] Opted-out contacts fully suppressed from future automated triggers, not just the current sequence
