## Approval Tier Table (example thresholds — calibrate to your own policy)

| Deviation Type | Tier 1 (Auto-log only) | Tier 2 (AM approval) | Tier 3 (Founder/Leadership approval) |
|---|---|---|---|
| Discount off list price | 0% (standard pricing) | ≤10% | >10% |
| Payment term deviation | Standard (per Stage 39) | Net 14 instead of Net 7 | Deferred/milestone-based payment |
| Scope customization | Within published tier | Minor add/remove of listed deliverables | Fully bespoke scope outside all tiers |
| Delivery timeline | Standard start date | Rush start (<7 days) at standard rate | Rush start with fee waived |

## Deal-Desk Request Template (submitted by rep)
```
Deal: [Prospect/Company Name]
Current stage: [Proposal Sent / Negotiation / Contract]
Request type: [Discount / Payment terms / Scope / Timeline]
Standard term: [what Stage 34/39 normally specifies]
Requested deviation: [specific ask]
Reason: [competitive pressure / cash-flow / strategic account / other — specify]
Deal value (standard terms): [amount]
Deal value (with requested deviation): [amount]
Requested by: [Rep name] | Date: [date]
```

## Approval Decision Log Template
```
Request ref: [link to deal-desk request]
Decision: [Approved / Rejected / Approved with modification]
Approver: [Name] | Tier: [1/2/3] | Date: [date]
Modified terms (if applicable): [specify]
Notes: [any conditions attached to the approval]
```

## Escalation Message (rep → approver)
```
Hi [Approver], requesting Tier [2/3] approval for [Prospect Company].
They're asking for [specific deviation] — reason given: [reason].
Standard deal value: [X] / requested: [Y].
Can you approve, reject, or suggest a middle ground? Deal is [time-sensitive/not] —
[context, e.g., "they want to sign by Friday"].
```
