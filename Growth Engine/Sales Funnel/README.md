# International B2B Sales Knowledge Base — Sales Funnel

Enterprise-grade, modular, version-controlled documentation of the full 54-stage International B2B Sales Funnel — from Market Research through Advocacy.

**Audience:** AI Agents, employees, freelancers, virtual assistants, managers, developers, automation engineers, sales/marketing/customer success teams, CRM/ERP systems.

**Status:** Structural skeleton complete (54 stages × 9 files = 486 files). Stage 06 (Lead Extraction) is fully populated as the quality-bar pilot; all other stages are correctly structured and cross-referenced but await full content population in subsequent passes.

## Folder Standard

Every stage folder contains: `README.md`, `methods.md`, `tools.md`, `automation.md`, `checklists.md`, `templates.md`, `resources.md`, `faq.md`, `references.md`. Additional files are added when a topic outgrows one file (see Stage 06 for an example of this expansion).
