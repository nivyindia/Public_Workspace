# FAQ — 26 Objection Handling

[⬅ Back to README](README.md)

**Q: What's the single most important rule in this stage?**
Never argue. Acknowledge the concern, reframe it, then probe with a question that keeps the conversation moving — the ARP framework.

**Q: What if a prospect raises an objection not in the library?**
Log it (see the New Objection Log Entry template) so it can be reviewed and added — the library should keep growing, not stay static.

**Q: Should reps read from the library verbatim during a live call?**
No — the library is study material to internalize before calls, not a script to read from live. Responses should sound natural, not recited.

**Q: How is this different from Stage 25 Reply Handling?**
Stage 25 classifies replies and handles the clear-cut categories directly. When a reply raises a genuine objection, Stage 25 routes it here for the correct response before a final reply is sent.

**Q: Does this library apply to live calls too?**
Yes — it's the shared reference for both written objection-carrying replies (Stage 25) and live-call objections (Stage 18 Cold Calling, Stage 29 Discovery Call).
