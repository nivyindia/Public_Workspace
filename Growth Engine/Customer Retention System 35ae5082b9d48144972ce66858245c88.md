# 💡 Retention Philosophy {#philosophy}

> **Acquiring a client costs 5–7x more than keeping one.** Every pound invested in retention compounds into lifetime value.
> 

**Our retention formula:**

1. **Excellent onboarding** — set expectations clearly, deliver fast first wins
2. **Consistent communication** — monthly reports, proactive updates
3. **Relationship investment** — know their business, celebrate their wins
4. **Proactive problem-solving** — identify issues before the client does
5. **Growth conversations** — continuously discuss how we can do more

# 🚀 Onboarding System {#onboarding}

**Week 1: Foundation**

- [ ]  Welcome email sent + intro call scheduled
- [ ]  Access requests sent (accounting software, website, social)
- [ ]  Onboarding questionnaire completed by client
- [ ]  Team assignments made (delivery team informed)
- [ ]  Kick-off call completed — goals aligned

**Week 2–4: First Delivery**

- [ ]  First deliverable completed and sent
- [ ]  Client feedback received and actioned
- [ ]  Check-in email: "How are things going so far?"

**Month 1 end: First Report**

- [ ]  Monthly report sent (work done, results, next steps)
- [ ]  30-day review call scheduled

# 📈 Upsell & Expansion System {#upsell}

**When to upsell:**

- Month 3+ — client has seen results and trust is established
- When a specific gap becomes visible during delivery
- During quarterly review calls

**Natural upsell paths:**

| If they have... | Offer... |
| --- | --- |
| Accounting only | Add IT support or website |
| IT/website only | Add SEO or social media marketing |
| Marketing only | Add bookkeeping or VA program |
| VA program | Add CRM setup (HubSpot) or automation (n8n) |
| Any service | Full-suite bundle at a discounted rate |

**Upsell framing:**

> "[Name], I’ve noticed [specific observation about their business]. We actually have a service that directly addresses that — and since you’re already a client, there’s no onboarding overhead. Would it be worth a quick chat about it?"
>

# 🚨 Churn Prevention {#churn}

**Early warning signs of churn:**

- Client response times getting longer
- Complaints about communication or quality
- Missed invoice payments
- Requests to pause or reduce scope
- Silence after a deliverable is sent

**Churn prevention response:**

1. Book a call immediately — don’t wait
2. Acknowledge any issues proactively
3. Offer a concrete improvement plan
4. If genuine dissatisfaction: offer 1 month free or partial refund as goodwill
5. If they want to leave anyway: exit gracefully, ask for honest feedback
