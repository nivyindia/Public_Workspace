## Your job in plain English

Find leads → Message them → Follow up → Book a call → Update CRM → Submit daily report.

That is your entire job. Every stage of training teaches you how to do one of those things better.

---

## Your daily report (submit every day by 7:00 PM)

```
DAILY REPORT — [Your Name] — [Date]
Leads Added: __
Messages Sent: __
Follow-ups Sent: __
Replies Received: __
Calls Booked: __
Platforms Used: __
Issues / Blockers: __
```

No report = marked absent. No exceptions.

---

## What you will be doing over 3 months

| Period | Focus | Key milestone |
| --- | --- | --- |
| Week 1 (Days 1–7) | Learn the system, start outreach | First message sent, CRM updated |
| Week 2 (Days 8–14) | Build consistency | 3–5 calls booked |
| Weeks 3–4 | Improve quality, handle objections | First qualified handover to closer |
| Month 2 | Full system integration | Stable daily performance |
| Month 3 | Peak performance or specialisation | 5–10 calls/week |
| Month 3+ (merit only) | Leadership track | Managing your own team |

---

## Your performance is measured on 5 things

| Metric | Target |
| --- | --- |
| Lead accuracy (correct ICP) | 90%+ |
| Message quality (scripts followed) | No deviations in first 2 weeks |
| CRM accuracy (updated after every action) | 100% same-day |
| KPI completion (daily targets hit) | 65%+ for full base salary |
| Report submission | 22+ reports in 30 days |
