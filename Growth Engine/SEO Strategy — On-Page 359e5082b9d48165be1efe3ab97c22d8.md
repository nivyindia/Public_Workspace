# ⚙️ Technical SEO Checklist {#technical}

- [ ]  Site loads under 3 seconds (test with PageSpeed Insights)
- [ ]  Mobile responsive on all devices
- [ ]  SSL certificate active (https://)
- [ ]  XML sitemap submitted to Google Search Console
- [ ]  Robots.txt correctly configured
- [ ]  Schema markup added (Organization, LocalBusiness, Service)
- [ ]  All pages have unique title tags (50–60 chars)
- [ ]  All pages have meta descriptions (150–160 chars)
- [ ]  No broken internal links
- [ ]  Images have descriptive alt text
- [ ]  H1 tag on every page, H2s used for structure
- [ ]  Canonical tags on duplicate or near-duplicate pages

---

# 📝 Content Optimisation Rules {#content}

1. **Target 1 primary keyword per page** — don't stuff multiple
2. **Include keyword in:** title, H1, first paragraph, one H2, URL slug, meta description
3. **Word count:** Service pages = 800–1200 words | Blog posts = 1500–2500 words
4. **Internal links:** Every page links to at least 2–3 other internal pages
5. **External links:** Include 1–2 authoritative external links per page
6. **Update content** every 6 months to signal freshness
7. **Add FAQs** to service pages — captures featured snippet opportunities
