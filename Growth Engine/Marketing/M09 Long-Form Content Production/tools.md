# M09 — Tools

Pulls from the shared free/OSS stack in `IMPLEMENTATION-PLAN.md` §2, plus stage-specific additions below. All pricing/limits marked "verify current" — free-tier terms change without notice.

## From the Shared Stack

| Function | Tool | Notes |
|---|---|---|
| AI drafting assist | Claude.ai / ChatGPT free tier | Draft-only, per QC rule — human rewrites before publish |
| Keyword input | Google Keyword Planner, Google Trends, Ubersuggest (free tier) | Feeds the brief from M04 |
| Workflow automation | n8n (self-hosted) | Powers Method 4 in `methods.md` |

## Stage-Specific Additions

| Function | Free / OSS tool | Notes | Paid upgrade path |
|---|---|---|---|
| Writing/editing | Google Docs | Free, real-time collaboration, comment threads for review gate | Google Workspace paid tiers only for admin/storage needs |
| Readability check | Hemingway Editor (free web version) | Flags overly complex sentences | Hemingway desktop app (one-time paid) |
| Grammar/clarity | Grammarly free tier | Basic grammar/spelling only on free tier — verify current feature gating | Grammarly Premium for tone/clarity suggestions |
| SERP competitive scan | Manual Google search + free browser extensions (e.g., MozBar free tier) | Enough for SMB-scale competitive scanning | Ahrefs/SEMrush content gap tools |
| Outline/brief structure | Google Docs template (see `templates.md`) | No dedicated tool needed | Content brief SaaS tools (Clearscope, Frase) once volume justifies |
| Stock/original imagery | Unsplash, Pexels (free, license-verify per image) | For in-post imagery | Canva Pro, paid stock libraries |
| Basic image editing | Canva free tier | Featured images, simple diagrams | Canva Pro |
| Version control | Google Docs version history, or Git if content lives in a repo | Free either way | — |

## Notes

- No tool in this list requires a paid tier to produce a publishable long-form post end-to-end.
- Verify current free-tier caps (Grammarly feature gating, Ubersuggest daily query limits, MozBar free-tier scope) before relying on them for volume production — these change without notice.
