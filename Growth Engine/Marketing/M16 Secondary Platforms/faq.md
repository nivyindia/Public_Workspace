# M16 — FAQ

**Q: Why is this stage's content mix/cadence sourced from a May 2026 doc — is it still current?**
A: The Social Media Platform Playbooks doc is dated May 2026 and marked 🟢 Complete at the source. Social
platform algorithms and best practices shift; treat the cadence and format guidance here as a
starting point and verify against current platform behavior periodically, per the Implementation
Plan's "verify current" convention (§2, §6).

**Q: Does this stage close leads?**
A: No. This stage does not close deals. Every DM reply, comment-to-DM conversion, or inbound lead this channel generates is logged and flows to **M22 (Inbound-to-CRM Bridge)**, which lands it in **Sales Funnel Stage 06 (Lead Extraction)** as an inbound record, same as every other Track M stage.

**Q: What happens if M10 (repurposing) isn't built yet?**
A: **M10 (Content Repurposing & Distribution Engine) status: pending.** Per the Implementation Plan (§3-§4), M10 was meant to be built before the social stages so M11-M16 could each link into a working repurposing pipeline instead of restating it. M10 has not been built yet, so this stage describes what it *will* consume from M10 (platform-native cuts of each long-form piece) without assuming that pipeline exists today. Until M10 is built, treat the repurposing step below as manual.

**Q: Can AI draft this stage's posts without human review?**
A: No. Every piece of AI-drafted copy for this channel is reviewed by a human before it is scheduled or published. This is a standing rule across all of Track M's automation.md files, not a suggestion specific to this stage (Implementation Plan §6).

**Q: Why free/OSS tools instead of the usual paid social tools?**
A: Per the Implementation Plan's Track M objective (§1), this stage's tools default to free/OSS options first. Paid tools are listed only as an optional upgrade path once volume justifies the cost.

## Platform-specific FAQ

**Q: Why does this stage only fully cover WhatsApp Channel and not Pinterest/Threads?**
A: The internal Social Media Platform Playbooks doc doesn't mention Pinterest or Threads at all. Rather than invent goals/cadence for them, this stage flags the gap (README.md) and treats those two platforms as needing founder input before they're built out to the same depth as the other four Track M social stages.
