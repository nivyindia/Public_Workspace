# M05 — On-Page SEO Implementation

**Phase:** B — SEO Engine
**Feeds:** M06 (Technical SEO & Site Health — shares the same pages), M21 (Marketing Analytics & Reporting)
**Fed by:** M04 (Keyword Research & Mapping), M09 (Long-Form Content Production)
**Build status:** 🟡 Built to pilot depth this session (Batch 2). See `references.md` for a data-gap note on raw material sourcing.

## Purpose

M05 takes the keyword-to-URL assignments from M04 and the drafted content from M09, and turns them into properly optimized live pages — title tags, meta descriptions, header structure, internal linking, and image optimization. This is the stage that makes a page actually eligible to rank for the term it was written for; M04 picks the target, M09 writes the words, M05 makes sure the page's structure and metadata reflect that target correctly.

## Inputs

- Assigned keyword-to-URL map (M04)
- Drafted or existing page content (M09, or an existing live page being re-optimized)
- Site's current CMS/platform (WordPress, Webflow, custom, etc. — determines which tools apply)

## Outputs

- Optimized page (title tag, meta description, H1–H3 structure, keyword placement, internal links, image alt text)
- On-page SEO checklist sign-off per page, logged against the M04 tracker row

## Sub-Stages

| # | Sub-stage | What it does |
|---|---|---|
| M05.1 | Title tag & meta description writing | Craft the clickable, keyword-relevant SERP snippet |
| M05.2 | Header structure & keyword placement | Organize H1–H3 around the target keyword and its supporting terms |
| M05.3 | Internal linking | Link the page to/from its pillar and related cluster articles (per M04.5's cluster map) |
| M05.4 | Image optimization | Compress, rename, and alt-tag every image for both SEO and accessibility |
| M05.5 | On-page QC & publish sign-off | Final checklist pass before the page goes live or an existing page's edit is pushed |

## How This Stage Is Used

Every page M09 produces, and every existing page flagged for re-optimization, passes through M05 before it's considered "done." The on-page checklist (`checklists.md`) is the actual gate — a page isn't marked live in the M04 tracker until it's signed off here.
