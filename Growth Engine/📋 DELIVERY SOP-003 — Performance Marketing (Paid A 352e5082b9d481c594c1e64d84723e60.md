## 📅 4-WEEK MONTHLY DELIVERY CYCLE

### WEEK 1 — SETUP & LAUNCH

**Day 1–2: Client Onboarding & Access**

- Collect ad account access (Meta Business Manager + Google Ads Manager)
- Collect brand assets: logo, product images, videos (min 3 creatives)
- Collect offer details: price, USP, CTA, landing page URL
- Confirm monthly ad budget (client-controlled) — log in delivery tracker
- Review existing campaigns (if any) — screenshot and archive baseline metrics
- Confirm target audience: age, gender, location, interests, exclusions

**Day 3–4: Campaign Architecture**

- Build campaign structure:
    - L1: 1 campaign → 2 ad sets → 3 ads
    - L2: 2 campaigns → 4 ad sets → 6 ads
    - L3: 3 campaigns → 6 ad sets → 9+ ads (includes retargeting)
- Set up Meta Pixel / Google Tag (verify firing correctly)
- Configure conversion events: Lead, Purchase, or custom (per client goal)
- Set up UTM parameters on all ad URLs
- Submit campaign to supervisor for pre-launch QC

**Day 5: Launch**

- Launch approved campaigns at 9 AM client timezone
- Monitor first 6 hours for delivery issues (ads stuck in review, zero delivery)
- Send client "Campaigns Live" update: screenshot of active campaigns + expected 48-hour learning period note

---

### WEEK 2 — MONITORING & FIRST OPTIMISATION

**Day 8–9: First Performance Check**

- Pull 7-day performance report: Impressions, Reach, CTR, CPC, CPL, ROAS
- Flag any ad sets with CTR below 1% or CPL above 3x target — pause or A/B test
- Check ad frequency — if frequency >3 on same audience, expand audience or refresh creative
- Check for policy violations or restricted content warnings

**Day 10: Creative Refresh (if needed)**

- If CTR < 1%: request 2 new creatives from client or design team
- Test new headline variants (minimum 2 per ad set at L2+)
- Document change in delivery tracker: what changed, why, expected impact

**Day 12: Week 2 Client Update**

- Send weekly snapshot: spend to date, leads generated, CPL, key observations
- Format: table (Week 1 vs Week 2) + 1 recommendation

---

### WEEK 3 — SCALING & RETARGETING (L2+)

**Day 15–16: Performance Analysis**

- Identify top-performing ad set (lowest CPL / highest ROAS)
- Scale winning ad set: increase budget by 20–30% (not more — avoid algorithm reset)
- Pause bottom 20% performers (by CPL or ROAS)
- L3: Launch retargeting campaign targeting website visitors (last 30 days) + video viewers (50% watched)

**Day 17–18: Audience Expansion (L2+)**

- Build lookalike audience from best-converting leads (1% LAL)
- Test lookalike ad set against interest-based ad set
- Document hypothesis: "Lookalike should outperform interest-based by X% based on Y data"

**Day 19: Week 3 Client Update**

- Send weekly snapshot: cumulative spend, total leads, CPL trend, ROAS trend
- Include scaling decisions and rationale

---

### WEEK 4 — FINAL PUSH & MONTHLY REPORTING

**Day 22–23: Final Week Optimisation**

- Final creative refresh if frequency > 4 on any ad set
- Confirm campaign pacing — check spend rate vs remaining budget
- Add any dayparting adjustments if data shows time-of-day patterns

**Day 26–28: Monthly Report Compilation**

- Pull full month data from Ads Manager
- Build monthly report using Nivy Performance Report Template:
    - Executive Summary (3 bullet points max)
    - Monthly Metrics Table: Impressions / Reach / CTR / Clicks / Leads / CPL / Spend / ROAS
    - Week-by-Week trend table
    - Top performing ad (screenshot + metrics)
    - Bottom performing ad (screenshot + what was done)
    - Next month recommendations (3 specific actions)
- Submit to supervisor for QC before sending to client

**Day 28–30: Client Report Delivery**

- Send monthly report via email + WhatsApp summary
- Schedule next month strategy call (L2+)
- Log report delivery date in delivery tracker

## ✅ QC CHECKLIST — PRE-LAUNCH

> Supervisor must sign off before any campaign goes live.
> 
- [ ]  Pixel/Tag verified firing on correct events
- [ ]  UTM parameters on all ad URLs
- [ ]  Campaign objective matches client goal (Leads vs Traffic vs Conversions)
- [ ]  Budget set correctly — daily or lifetime confirmed with client
- [ ]  Ad copy reviewed: no policy violations (no "you", no before/after, no financial guarantees)
- [ ]  CTA matches landing page offer (no bait-and-switch)
- [ ]  All creatives approved by client in writing (WhatsApp/email screenshot saved)
- [ ]  Audience exclusions set (existing customers excluded from cold campaigns)
- [ ]  Frequency cap set (L3 only)
- [ ]  Campaign naming convention followed: [CLIENT]-[CAMPAIGN TYPE]-[DATE]

---

## ✅ QC CHECKLIST — WEEKLY

- [ ]  Weekly snapshot sent to client by Day 12 / 19 / 26
- [ ]  No ad set running with CTR < 0.5% for more than 5 days without action
- [ ]  No ad set spending > 40% of budget without review
- [ ]  Any budget changes logged in delivery tracker with rationale
- [ ]  Frequency monitored — no ad set above frequency 5 without creative refresh

## 📊 KPI STANDARDS TABLE

| KPI | L1 Starter Target | L2 Growth Target | L3 System Target | Escalation Trigger |
| --- | --- | --- | --- | --- |
| CTR (Link) | > 1.0% | > 1.5% | > 2.0% | < 0.5% for 5+ days |
| CPL (Lead) | < 3x client target | < 2x client target | = client target | > 4x target for 7+ days |
| ROAS (if ecommerce) | > 1.5x | > 2.5x | > 3.5x | < 1.0x for 7+ days |
| Ad Frequency | < 3 (cold) | < 3 (cold) | < 3 cold / < 5 retarget | > 5 any audience |
| Spend Pacing | ±20% of target | ±15% of target | ±10% of target | > ±25% without approval |
| Report Delivery | By Day 28 | By Day 27 | By Day 26 | Day 30+ = SLA breach |

## 🚨 ESCALATION RULES

| Situation | Action | Escalate To |
| --- | --- | --- |
| Account restricted or banned | Pause all campaigns. Screenshot everything. DO NOT appeal without supervisor sign-off. | Supervisor immediately |
| CPL > 5x target for 7+ days | Do not continue spending. Pause campaigns. Present 3-option plan to supervisor. | Supervisor same day |
| Client disputes ad spend | Do not engage. Forward all screenshots to supervisor. | Supervisor immediately |
| Landing page down (404) | Pause campaigns immediately. Notify client + supervisor within 1 hour. | Client + Supervisor |
| Client requests budget increase > 50% | Do not implement without written confirmation + supervisor review. | Supervisor |
| Creative violates policy (ad rejected) | Do not resubmit same creative. Request revised creative from client. Log in tracker. | Note in tracker |
| Zero delivery for 24+ hours after launch | Check payment method, pixel, audience size, policy hold. Escalate if unresolved. | Supervisor |
