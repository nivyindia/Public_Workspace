# 5. CRM Access & Setup

The CRM is the most important tool you will use every single day. Every lead, every message, every follow-up must be recorded here.

- [ ]  CRM Google Sheet link received from supervisor
- [ ]  Sheet opened and columns understood
- [ ]  Test entry added and deleted to confirm edit access

## CRM columns you will fill daily

| Column | What to enter |
| --- | --- |
| Name | Lead's full name |
| Company | Company name |
| Role | Owner / Founder / CEO |
| Industry | Roofing / HVAC / Agency etc. |
| Country | USA / UK / AUS / Canada |
| LinkedIn URL | Direct profile link |
| Website | Company website |
| Email | If found |
| Platform | Where you found/messaged them |
| Status | New / Messaged / Replied / Interested / Booked / No Response |
| Last contact date | Date of last message |
| Next follow-up date | When to follow up next |
| Notes | Key details from conversation |

## CRM status flow — memorise this

**CRM status flow:** New → Messaged → Replied → Interested → Booked → No Response

> Update the CRM after every single action. Skipping even one update breaks the entire follow-up system. No CRM update = the lead is lost.
