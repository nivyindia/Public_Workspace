# 📅 Weekly Operating Rhythm

Monday to Friday cadence. Run this every week without exception.

---

## Monday — Start Strong

- [ ]  Review last week's team metrics (outreach, bookings, follow-up rate)
- [ ]  Review Supervisor EOD report from Friday
- [ ]  Set this week's team targets (outreach volume, booking goal)
- [ ]  Brief Supervisor on this week's focus
- [ ]  Check System Feedback Log for any open issues

---

## Tuesday & Thursday — Monitor

- [ ]  Check Supervisor's daily reports
- [ ]  Respond to any escalations within 4 hours
- [ ]  Review any flags in Supervisor Tracking & QC System

---

## Wednesday — Mid-Week QC Review

- [ ]  1:1 with Supervisor (15–20 min)
- [ ]  Review 3-5 VA conversations personally (cross-check Supervisor's QC)
- [ ]  Review current progression candidates: anyone ready to advance a stage?
- [ ]  Identify any training gaps

---

## Friday — Close the Week

- [ ]  Review full week metrics vs targets
- [ ]  Write and submit EOW (End of Week) report
- [ ]  Complete any pending progression reviews
- [ ]  Update System Health Dashboard
- [ ]  Flag any system issues in System Feedback Log
- [ ]  Brief Supervisor on next week's expectations
