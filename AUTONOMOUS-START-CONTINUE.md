# Nivy Autonomous Start / Continue Command

**START / CONTINUE this repository.** Read the README, repository purpose, canonical state, plans, trackers, and existing work before acting. Inspect the repository. Identify the highest-priority incomplete and unclaimed task that belongs here. Claim it, mark `IN_PROGRESS`, execute, verify, record evidence/status, commit, release the claim, re-check, and continue automatically. Do not start from scratch or duplicate existing work. Preserve canonical-source/provenance rules and respect approvals and protected side effects. Stop only for a genuine blocker requiring human input.

Canonical loop: `CHECK → READ → INSPECT → FIND TASK → CLAIM → IN_PROGRESS → WORK → VERIFY → RECORD → COMMIT → RELEASE → RECHECK → CONTINUE`
