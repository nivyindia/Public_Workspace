## Organization

CEO owns strategy, capital allocation, major decisions and company-level outcomes.

COO owns cross-functional execution and operations.

CTO owns technology, automation, infrastructure and security.

Core functions include Sales, Marketing/Growth, Lead Generation, Delivery, QA, HR, Finance, Vendor Management and Technology/Automation.

## L1–L5

| Level | Responsibility |
|---|---|
| L1 | Execute SOP-defined work |
| L2 | Independently own specialist output |
| L3 | Own team/process/results |
| L4 | Own department outcomes |
| L5 | Own company-level outcomes |

## Hiring Workflow

Approved Headcount → JD → Sourcing → Screening → Skill Test → Interview → Practical Trial → Scorecard → Offer → Onboarding.

## Candidate Scorecard

| Component | Weight |
|---|---:|
| Functional Skill | 20% |
| Skill Test | 30% |
| Problem Solving | 15% |
| Communication | 10% |
| Ownership | 10% |
| Practical Trial | 15% |

85+ = Strong Hire; 75–84 = Hire; 65–74 = Hold; below 65 = Reject, subject to role-specific review.

## Compensation Planning Bands

| Level | Planning Range |
|---|---:|
| L1 | ₹18k–₹30k/month |
| L2 | ₹30k–₹55k/month |
| L3 | ₹55k–₹1L/month |
| L4 | ₹1L–₹2L/month |
| L5 | ₹2L–₹4L+/month |

These are planning bands, not guaranteed market offers.

## KPI Principle

Every KPI should have a definition, formula, source, owner, verifier, target and threshold.

Activity → Output → Verified Output → Business Outcome.

## QA

Self-check → Team Lead Review → Independent QA → Pass/Rework → Final Acceptance.

QA should remain sufficiently independent from the function being audited.

## Core Revenue Flow

Marketing → Lead Generation → Sales → Client → Delivery → Retention → Upsell.

## Client Delivery

Sale → Handoff → Onboarding → Requirements → Planning → Execution → QA → Delivery → Feedback → Revision → Acceptance → Renewal/Upsell.

## Outsourcing

Requirement → Vendor Sourcing → Screening → Test → Paid Pilot → QA → Acceptance → Payment → Vendor Rating.

## Finance / Unit Economics

Track revenue, direct delivery cost, contribution margin, payroll, operating expenses, cash flow, profitability and revenue per FTE.

Illustrative lean-team planning previously modeled approximately 18 people and ₹10.75L/month in base salary cost before employer-loaded costs and other operating expenses.

## Workforce Planning

Required Headcount = Forecast Workload ÷ Sustainable Capacity per Person + appropriate capacity buffer.

Hiring should be triggered by sustained workload, insufficient capacity, documented SOPs and viable economics—not simply by temporary busyness.

## Security

Detect → Contain → Assess → Escalate → Remediate → Verify → Document → Prevent Recurrence.

## Business Continuity

Every critical system/process should have an owner, backup method and recovery procedure. Backups should be restore-tested.

## Legal & Compliance

Contracts, employment documents, client/vendor agreements, IP, confidentiality, data/privacy obligations and statutory/compliance deadlines should have defined ownership and appropriate professional review.

## Customer Success

Sale → Handoff → Onboarding → Delivery → Health Check → Feedback → Renewal → Upsell.

## Data / BI

Activity → Operational System → Validated Data → KPI Layer → Dashboard → Management Decision.

## 90-Day Implementation

### Days 1–7
- Freeze org chart and department ownership
- Finalize compensation bands
- Establish SOP repository
- Define KPI dictionary
- Establish access matrix
- Define hiring priorities

### Days 8–15
- Launch daily, weekly and monthly dashboards
- Establish management review cadence

### Days 16–30
- Implement standardized hiring workflow, tests and scorecards

### Days 31–45
- Launch core Sales, Lead Generation, Delivery and Technology workflows

### Days 46–60
- Implement QA sampling, defect tracking and corrective actions

### Days 61–75
- Automate repetitive reporting and operational workflows

### Days 76–90
- Optimize based on revenue/FTE, margin, QA, utilization, retention and automation metrics

## Operating Templates

### Daily Work Report

Employee, date, priority, planned tasks, completed tasks, evidence, blockers and escalation.

### Weekly Department Report

KPI target vs actual, QA, capacity, people, issues, corrective actions and next-week priorities.

### Escalation Record

Issue, severity, business impact, immediate action, owner, deadline, escalation recipient and resolution.

### SOP Change Request

SOP ID, current version, requested change, reason, impact, requester, reviewer, approver and new version.

### Vendor Scorecard

Quality, on-time delivery, cost, communication, reliability and capacity.

## Final Control Principle

Every action item should have:

**Owner + Deadline + Expected Output + Verification.**
